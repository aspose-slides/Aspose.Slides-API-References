## Απαρίθμηση EmbeddingLevel

Αντιπροσωπεί τα δικαιώματα αδειοδότησης για την ενσωμάτωση της γραμματοσειράς.

```csharp
[Flags]
public enum EmbeddingLevel : ushort
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Installable | `0` | Οι γραμματοσειρές με αυτή τη ρύθμιση δείχνουν ότι μπορούν να ενσωματωθούν και να εγκατασταθούν μόνιμα στο απομακρυσμένο σύστημα από μια εφαρμογή. Ο χρήστης του απομακρυσμένου συστήματος αποκτά τα ίδια δικαιώματα, υποχρεώσεις και άδειες για αυτή τη γραμματοσειρά όπως ο αρχικός αγοραστής της γραμματοσειράς και υπόκειται στην ίδια συμφωνία τελικού χρήστη, πνευματικά δικαιώματα, σχεδιαστικό πατέντο και/ή εμπορικό σήμα όπως ο αρχικός αγοραστής. |
| Restricted | `2` | Οι γραμματοσειρές που έχουν μόνο αυτό το bit ορισμένο δεν πρέπει να τροποποιηθούν, ενσωματωθούν ή ανταλλαχθούν με οποιονδήποτε τρόπο χωρίς πρώτα να ληφθεί η άδεια του νόμιμου ιδιοκτήτη. |
| PreviewPrint | `4` | Όταν αυτό το bit είναι ορισμένο, η γραμματοσειρά μπορεί να ενσωματωθεί και να φορτωθεί προσωρινά στο απομακρυσμένο σύστημα. Τα έγγραφα που περιέχουν γραμματοσειρές Preview &amp; Print πρέπει να ανοίγονται "read-only"· δεν μπορούν να γίνουν επεξεργασίες στο έγγραφο. |
| Editable | `8` | Όταν αυτό το bit είναι ορισμένο, η γραμματοσειρά μπορεί να ενσωματωθεί αλλά πρέπει να εγκατασταθεί μόνο προσωρινά σε άλλα συστήματα. Σε αντίθεση με τις γραμματοσειρές Preview &amp; Print, τα έγγραφα που περιέχουν γραμματοσειρές Editable μπορούν να ανοίγονται για ανάγνωση, η επεξεργασία επιτρέπεται και οι αλλαγές μπορούν να αποθηκευτούν. |
| NoSubsetting | `100` | Όταν αυτό το bit είναι ορισμένο, η γραμματοσειρά δεν μπορεί να υπο-υποσυνολοποιηθεί πριν την ενσωμάτωση. Άλλοι περιορισμοί ενσωμάτωσης που καθορίζονται στα bits 0-3 και 9 ισχύουν επίσης. |
| BitmapOnly | `200` | Όταν αυτό το bit είναι ορισμένο, μόνο τα bitmap που περιέχονται στη γραμματοσειρά μπορούν να ενσωματωθούν. Δεν μπορούν να ενσωματωθούν δεδομένα περίγραμμα. Εάν δεν υπάρχουν διαθέσιμα bitmap στη γραμματοσειρά, τότε η γραμματοσειρά θεωρείται μη εφικτή για ενσωμάτωση και οι υπηρεσίες ενσωμάτωσης θα αποτύχουν. |
