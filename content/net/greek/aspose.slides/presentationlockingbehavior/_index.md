## Απαρίθμηση PresentationLockingBehavior

Αντιπροσωπεύει τη συμπεριφορά σχετικά με τη διαχείριση της πηγής [`IPresentation`](../ipresentation) (αρχείο ή Stream) κατά τη φόρτωση και εργασία με ένα παράδειγμα του [`IPresentation`](../ipresentation).

```csharp
public enum PresentationLockingBehavior
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| LoadAndRelease | `0` | Η πηγή θα κλειδωθεί μόνο για τη διάρκεια της εκτέλεσης του κατασκευαστή [`IPresentation`](../ipresentation). Εάν το [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) οριστεί σε false, όλα τα BLOB θα φορτωθούν στη μνήμη. Διαφορετικά, ενδέχεται να χρησιμοποιηθούν άλλα μέσα, όπως προσωρινά αρχεία.Αυτή η συμπεριφορά είναι πιο αργή από το KeepLocked, και εάν είναι δυνατόν να μεταβιβαστεί η ιδιοκτησία της πηγής στο [`IPresentation`](../ipresentation), συνιστάται η χρήση του KeepLocked. |
| KeepLocked | `1` | Η πηγή θα κλειδωθεί για ολόκληρη τη διάρκεια ζωής του αντικειμένου [`IPresentation`](../ipresentation), μέχρι να διαγραφεί. Το [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) πρέπει να οριστεί σε true για τη χρήση αυτής της συμπεριφοράς, διαφορετικά θα προκληθεί εξαίρεση.Αυτή η συμπεριφορά συνιστάται, είναι πιο γρήγορη και καταναλώνει λιγότερη μνήμη από το LoadAndRelease. |

### Σχόλια

Η πηγή είναι η παράμετρος που περνάται στον κατασκευαστή [`IPresentation`](../ipresentation). Στο παρακάτω παράδειγμα, η πηγή είναι το αρχείο "pres.pptx":

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

Για αυτό το παράδειγμα, η πηγή (αρχείο "pres.pptx") θα κλειδωθεί για τη διάρκεια ζωής ενός αντικειμένου [`IPresentation`](../ipresentation), δηλαδή δεν μπορεί να αλλάξει ή διαγραφεί από άλλη διαδικασία.
