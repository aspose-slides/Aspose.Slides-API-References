## Presentation.RefreshChartsData method

Φορτώνει ξανά τα δεδομένα για όλα τα γραφήματα στην παρουσίαση από τα πηγαία βιβλία εργασίας.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| skipFailedCharts | Boolean | Καθορίζει αν η διαδικασία ανανέωσης συνεχίζει εάν ένα γράφημα αποτύχει να ενημερωθεί. Εάν `true`, τα γραφήματα που προκαλούν εξαίρεση παραλείπονται· διαφορετικά η εξαίρεση διαδίδεται. |

### Παραδείγματα

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
