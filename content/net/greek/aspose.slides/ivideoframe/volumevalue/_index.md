## IVideoFrame.VolumeValue ιδιότητα

Επιστρέφει ή ορίζει την ακριβή ένταση βίντεο ως ποσοστό. Η τιμή εκφράζεται ως ποσοστό από 0 έως 100. Χρησιμοποιήστε αυτήν την ιδιότητα για ανάγνωση ή ορισμό τιμών έντασης που είναι πιο ακριβείς από τα προκαθορισμένα επίπεδα που διατίθενται μέσω της ιδιότητας [`Volume`](../volume). Ανάγνωση/εγγραφή Single.

```csharp
public float VolumeValue { get; set; }
```

### Παραδείγματα

Παράδειγμα:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Διαβάστε την τρέχουσα ακριβή ένταση και ορίστε την στο 75,5 τοις εκατό.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
