## FontsManager.PreferRegisteredFontsOverEmbedded ιδιότητα

Καθορίζει εάν οι καταχωρημένες γραμματοσειρές πρέπει να προτιμώνται αντί των ενσωματωμένων γραμματοσειρών με το ίδιο όνομα και στυλ γραμματοσειράς. Όταν είναι ενεργοποιημένη, οι αντίστοιχες ενσωματωμένες γραμματοσειρές αντικαθίστανται προσωρινά με τις αντίστοιχες καταχωρημένες γραμματοσειρές κατά την εξαγωγή.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Παρατηρήσεις

Η προεπιλογή είναι **false**.

### Παραδείγματα

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
