## IPresentation.RefreshChartsData μέθοδος

Επαναφορτώνει τα δεδομένα για όλα τα γραφήματα στην παρουσίαση από τα βιβλία εργασίας προέλευσης.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| skipFailedCharts | Boolean | Καθορίζει εάν η διαδικασία ανανέωσης συνεχίζεται εάν ένα γράφημα αποτύχει να ενημερωθεί. Εάν `true`, τα γραφήματα που προκαλούν εξαίρεση παραλείπονται· διαφορετικά η εξαίρεση διαδίδεται. |

### Παραδείγματα

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
