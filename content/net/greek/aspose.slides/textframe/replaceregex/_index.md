## TextFrame.ReplaceRegex μέθοδος

Αντικαθιστά όλα τα ταιριάσματα της κανονικής έκφρασης με το καθορισμένο κείμενο.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| regex | Regex | Η κανονική έκφραση Regex για λήψη των συμβολοσειρών που θα αντικατασταθούν. |
| newText | String | Η συμβολοσειρά για αντικατάσταση όλων των εμφανίσεων των συμβολοσειρών που θα αντικατασταθούν. |
| callback | IFindResultCallback | Αντικείμενο callback για την αποθήκευση του αποτελέσματος της λειτουργίας αντικατάστασης [`IFindResultCallback`](../../ifindresultcallback). |

### Παραδείγματα

Ο παρακάτω κώδικας παραδείγματος δείχνει πώς να αντικαταστήσετε κείμενο χρησιμοποιώντας κανονική έκφραση με καθορισμένο κείμενο.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Αντικαθιστά όλες τις λέξεις με 10 ή περισσότερους χαρακτήρες με '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
