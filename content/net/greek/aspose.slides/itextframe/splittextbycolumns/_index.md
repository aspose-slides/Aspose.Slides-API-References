## ITextFrame.SplitTextByColumns μέθοδος

Διαιρεί το περιεχόμενο κειμένου του [`ITextFrame`](../../itextframe) σε έναν πίνακα συμβολοσειρών, όπου κάθε στοιχείο αντιστοιχεί σε ξεχωριστή στήλη κειμένου μέσα στο πλαίσιο.

```csharp
public string[] SplitTextByColumns()
```

### Τιμή Επιστροφής

Ένας πίνακας συμβολοσειρών, όπου κάθε συμβολοσειρά αντιπροσωπεύει το περιεχόμενο κειμένου μιας συγκεκριμένης στήλης στο [`ITextFrame`](../../itextframe).

### Σχόλια

Εάν το πλαίσιο κειμένου δεν περιέχει πολλαπλές στήλες, ο επιστρεφόμενος πίνακας θα έχει ένα ενιαίο στοιχείο που περιέχει ολόκληρο το κείμενο. Οι κενές στήλες θα αντιπροσωπεύονται ως κενές συμβολοσειρές στον πίνακα.

### Παραδείγματα

Το παρακάτω παράδειγμα δείχνει πώς να χρησιμοποιήσετε το `SplitTextByColumns`:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // Λάβετε το πρώτο σχήμα στη διαφάνεια και μετατρέψτε το σε ITextFrame
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // Διαιρέστε το περιεχόμενο του πλαισίου κειμένου σε στήλες
    string[] columnsText = textFrame.SplitTextByColumns();
    // Εκτυπώστε το κείμενο κάθε στήλης στην κονσόλα
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
