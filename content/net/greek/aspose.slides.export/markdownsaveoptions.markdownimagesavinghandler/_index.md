## MarkdownSaveOptions.MarkdownImageSavingHandler delegate

Καλείται για κάθε εικόνα που δεν είναι SVG (bitmap ή metafile) κατά την εξαγωγή Markdown. Επιστρέψτε `true` για να χρησιμοποιήσετε το καθορισμένο *link*, ή `false` για να εφαρμόσετε την προεπιλεγμένη λογική αποθήκευσης.

```csharp
public delegate bool MarkdownImageSavingHandler(IImage image, ImageFormat format, ref string link);
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| image | IImage | Η εικόνα που εξάγεται (bitmap ή metafile). |
| format | ImageFormat | Η μορφή εικόνας. |
| link | String& | Ο σύνδεσμος Markdown που θα χρησιμοποιηθεί κατά την επιστροφή `true`. |
