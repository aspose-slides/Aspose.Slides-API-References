## IMathBox διασύνδεση

Καθορίζει τη λογική συσκευασία (packaging) μαθηματικού στοιχείου. Για παράδειγμα, ένα αντικείμενο σε κουτί μπορεί να λειτουργήσει ως προσομοίωση τελεστή με ή χωρίς σημείο στοίχισης, να λειτουργήσει ως σημείο αλλαγής γραμμής, ή να ομαδοποιηθεί ώστε να μην επιτρέπει αλλαγές γραμμής εντός του. Για παράδειγμα, ο τελεστής \"==\" πρέπει να τοποθετηθεί σε κουτί για να αποτρέπεται η αλλαγή γραμμής.

```csharp
public interface IMathBox : IMathElement
```
