## MathJustification αρίθμηση

Καθορίζει τη στοίχιση της παράγραφου μαθηματικών (μια σειρά διπλασιασμένων εμφανίσεων μαθηματικού κειμένου μέσα στην ίδια παράγραφο)

```csharp
public enum MathJustification
```

### Τιμές

| Name | Value | Description |
| --- | --- | --- |
| LeftJustified | `1` | Στοίχιση μαθηματικού κειμένου προς τα αριστερά |
| RightJustified | `2` | Στοίχιση μαθηματικού κειμένου προς τα δεξιά |
| Centered | `3` | Στοίχιση μαθηματικού κειμένου στο κέντρο |
| CenteredAsGroup | `4` | Στοίχιση στο κέντρο της σελίδας ολόκληρης της ομάδας μαθηματικών μπλοκ ως μία ενιαία μονάδα. Αυτό σημαίνει ότι οι εμφανίσεις μαθηματικού κειμένου μπορούν να στοιχίζονται μεταξύ τους, αλλά η ολόκληρη ομάδα μαθηματικού κειμένου κεντράρεται συνολικά. |
