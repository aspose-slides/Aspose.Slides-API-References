## Compress.CompressImages μέθοδος

Μειώνει την ανάλυση των εικόνων στην παρουσίαση και διαγράφει τις περικομμένες περιοχές τους, παρόμοια με τη λειτουργία «Συμπίεση Εικόνων» του PowerPoint που εφαρμόζεται σε όλες τις εικόνες. Επεξεργάζονται οι εικόνες στις διαφάνειες, στις διαφάνειες διάταξης και στις κύριες διαφάνειες, συμπεριλαμβανομένων των εικόνων μέσα σε ομαδικά σχήματα και των γεμισμάτων εικόνας των σ shapes.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| presentation | IPresentation | Η παρουσίαση προς επεξεργασία. |
| resolution | PicturesCompression | Η στόχευση ανάλυσης σε σχέση με το μέγεθος με το οποίο εμφανίζεται κάθε εικόνα. DocumentResolution αφήνει τις εικόνες αμετάβλητες. |

### Εξαιρέσεις

| εξαίρεση | συνθήκη |
| --- | --- |
| ArgumentNullException | *παρουσίαση* είναι `null`. |

### Παρατηρήσεις

Οι εικόνες που είναι ήδη στη στόχευση ανάλυση ή χαμηλότερη παραμένουν αμετάβλητες· οι εικόνες δεν αυξάνονται ποτέ σε ανάλυση.

Δεν επεξεργάζονται: φόντο διαφανειών, γέμισμα κελιών πινάκων, διαγράμματα, SmartArt, εικόνες GIF (για διατήρηση κίνησης), εικόνες SVG και μετααρχείου (EMF/WMF).

Οι πεπερασμένες περιοχές αφαιρούνται μόνιμα και δεν μπορούν να επαναφερθούν στο PowerPoint.

### Παραδείγματα

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
