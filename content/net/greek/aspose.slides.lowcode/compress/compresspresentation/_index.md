## Compress.CompressPresentation μέθοδος

Μειώνει το μέγεθος μιας παρουσίασης εφαρμόζοντας όλα τα διαθέσιμα βήματα συμπίεσης:

* Αφαιρεί αχρησιμοποίητες κύριες διαφάνειες [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Αφαιρεί αχρησιμοποίητες διαφάνειες διάταξης [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Κρατά μόνο τα γλυφικά που χρησιμοποιούνται στις ενσωματωμένες γραμματοσειρές [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Μειώνει την ανάλυση εικόνας στα 150 DPI και διαγράφει τις περικομμένες περιοχές των εικόνων [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| presentation | Presentation | Η παρουσίαση προς συμπίεση. |

### Εξαιρέσεις

| εξαίρεση | συνθήκη |
| --- | --- |
| ArgumentNullException | *presentation* είναι `null`. |

### Σχόλια

Για προσαρμογή της συμπίεσης, για παράδειγμα για χρήση διαφορετικής ανάλυσης εικόνας ή για παράκαμψη ενός βήματος, καλέστε τις μεθόδους που παρατίθενται παραπάνω ξεχωριστά αντί για αυτήν. Οι περικομμένες περιοχές των εικόνων διαγράφονται μόνιμα και δεν μπορούν να αποκατασταθούν στο PowerPoint.

### Παραδείγματα

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
