## IDataLabelCollection.IsVisible ιδιότητα

False σημαίνει ότι η ετικέτα δεδομένων δεν είναι ορατή από προεπιλογή (και έτσι όλες οι Show*-flags (ShowValue, ...) του DefaultDataLabelFormat ιδιότητα είναι false). Μόνο για ανάγνωση Boolean.

```csharp
public bool IsVisible { get; }
```

### Σχόλια

Αν η ετικέτα δεδομένων είναι ορατή από προεπιλογή, μπορείτε να την κρύψετε από προεπιλογή με τη μέθοδο Hide(). Αλλά αν η ετικέτα δεδομένων δεν είναι ορατή από προεπιλογή (IsVisible είναι false) μπορείτε να κάνετε την ετικέτα δεδομένων «ορατή από προεπιλογή» ορίζοντας τις Show*-flags (ShowValue, ...) του DefaultDataLabelFormat ιδιότητα σε κατάσταση true.
