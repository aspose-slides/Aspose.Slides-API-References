## IDataLabel.LabelShapeType ιδιότητα

Λαμβάνει ή ορίζει τον τύπο σχήματος της ετικέτας δεδομένων. Επιστρέφει NotDefined εάν δεν έχει οριστεί σχήμα.

```csharp
public ShapeType LabelShapeType { get; set; }
```

### Παραδείγματα

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Ορίστε τον τύπο σχήματος της πρώτης ετικέτας δεδομένων σε Ellipse.

    pres.Save("ChartWithEllipseLabel.pptx", SaveFormat.Pptx);
}
```
