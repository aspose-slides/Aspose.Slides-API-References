## DataLabelCollection.DefaultLabelShapeType ιδιότητα

Ανακτά ή ορίζει τον προεπιλεγμένο τύπο σχήματος για ετικέτες δεδομένων. Επιστρέφει NotDefined αν δεν έχει οριστεί σχήμα.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Παρατηρήσεις

Ο καθορισμός αυτής της ιδιότητας επίσης ορίζει την ιδιότητα [`LabelShapeType`](../../idatalabel/labelshapetype) για όλες τις ετικέτες δεδομένων στη συλλογή στην ίδια τιμή.

### Παραδείγματα

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Ορίστε τον τύπο σχήματος για όλες τις ετικέτες δεδομένων στην πρώτη σειρά σε Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
