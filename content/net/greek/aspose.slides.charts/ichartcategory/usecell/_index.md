## IChartCategory.UseCell ιδιότητα

Αν είναι true, τότε η ιδιότητα AsCell είναι ενεργή. Με άλλα λόγια, το worksheet χρησιμοποιείται για την αποθήκευση της κατηγορίας (αυτή η περίπτωση υποστηρίζει κατηγορία πολλαπλών επιπέδων). Αν είναι false, τότε η ιδιότητα AsLiteral είναι ενεργή. Με άλλα λόγια, το worksheet ΔΕΝ χρησιμοποιείται για την αποθήκευση της κατηγορίας (και αυτή η περίπτωση δεν υποστηρίζει κατηγορίες πολλαπλών επιπέδων). Boolean μόνο για ανάγνωση.

```csharp
public bool UseCell { get; }
```

### Παρατηρήσεις

Για την αλλαγή τιμής αυτής της ιδιότητας (για όλες τις κατηγορίες στη συλλογή) ορίστε τη νέα τιμή στην ιδιότητα ChartCategoryCollection.UseCells.
