## SetExternalWorkbook(string) {#setexternalworkbook}

Ορίζει το εξωτερικό βιβλίο εργασίας ως πηγή δεδομένων για το διάγραμμα. Τα δεδομένα του διαγράμματος θα ενημερωθούν από το βιβλίο εργασίας προορισμού.

```csharp
public void SetExternalWorkbook(string workbookPath)
```

| Parameter | Type | Description |
| --- | --- | --- |
| workbookPath | String | Διαδρομή προς το βιβλίο εργασίας προορισμού |

### Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Το εξωτερικό βιβλίο εργασίας δεν είναι διαθέσιμο ή δεν μπορεί να φορτωθεί. |

### Examples

```csharp
[C#]
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;
   (chartData as ChartData).SetExternalWorkbook("../../workbook.xlsx");

```

## SetExternalWorkbook(string, bool) {#setexternalworkbook_1}

Ορίζει το εξωτερικό βιβλίο εργασίας ως πηγή δεδομένων για το διάγραμμα.

```csharp
public void SetExternalWorkbook(string workbookPath, bool updateChartData)
```

| Parameter | Type | Description |
| --- | --- | --- |
| workbookPath | String | Διαδρομή προς το βιβλίο εργασίας προορισμού |
| updateChartData | Boolean | Αν η τιμή είναι false, μόνο η διαδρομή του βιβλίου εργασίας θα ενημερωθεί. Τα δεδομένα του διαγράμματος δεν θα φορτωθούν και δεν θα ενημερωθούν από το βιβλίο εργασίας προορισμού. Μπορεί να χρησιμοποιηθεί όταν το βιβλίο εργασίας προορισμού δεν υπάρχει ή δεν είναι διαθέσιμο. Αν η τιμή είναι true, τα δεδομένα του διαγράμματος θα ενημερωθούν από το βιβλίο εργασίας προορισμού. |

### Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Το εξωτερικό βιβλίο εργασίας δεν είναι διαθέσιμο ή δεν μπορεί να φορτωθεί. |

### Examples

```csharp
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;

   (chartData as ChartData).SetExternalWorkbook("http://path/doesnt/exists", false);
```
