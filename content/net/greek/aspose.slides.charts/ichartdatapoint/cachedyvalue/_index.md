## IChartDataPoint.CachedYValue ιδιότητα

Επιστρέφει την αποθηκευμένη τιμή Y ενός σημείου δεδομένων διαγράμματος. Μόνο για ανάγνωση [`ICachedChartValue`](../../icachedchartvalue).

```csharp
public ICachedChartValue CachedYValue { get; }
```

### Παραδείγματα

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // Εκτυπώνει όλες τις αποθηκευμένες τιμές Y των σειρών του διαγράμματος.
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedYValue.ToDouble());
    }
}
```
