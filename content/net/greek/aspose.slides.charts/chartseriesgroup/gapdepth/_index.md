## ChartSeriesGroup.GapDepth ιδιότητα

Λαμβάνει ή ορίζει την απόσταση μεταξύ σειρών δεδομένων σε γράφημα 3D, ως ποσοστό του πλάτους του δείκτη. Η τιμή πρέπει να είναι μεταξύ 0 και 500. Ανάγνωση/εγγραφή UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### Παρατηρήσεις

Αυτή η ιδιότητα εφαρμόζεται σε σειρές των ακόλουθων τύπων: υποτύποι 3D ράβδων και στηλών (δείτε επίσης τη μέθοδο [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart)), Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
