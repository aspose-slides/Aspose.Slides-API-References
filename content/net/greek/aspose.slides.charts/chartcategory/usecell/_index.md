## ChartCategory.UseCell ιδιότητα

Αν είναι true, η ιδιότητα AsCell είναι ενεργή. Με άλλα λόγια, το worksheet χρησιμοποιείται για την αποθήκευση της κατηγορίας (αυτή η περίπτωση υποστηρίζει μια πολυεπίπεδη κατηγορία). Αν είναι false, η ιδιότητα AsLiteral είναι ενεργή. Με άλλα λόγια, το worksheet ΔΕΝ χρησιμοποιείται για την αποθήκευση της κατηγορίας (και αυτή η περίπτωση δεν υποστηρίζει πολυεπίπεδες κατηγορίες). Μόνο για ανάγνωση Boolean.

```csharp
public bool UseCell { get; }
```

### Σχόλια

Για να αλλάξετε την τιμή της ιδιότητας (για όλες τις κατηγορίες στη συλλογή), ορίστε τη νέα τιμή στην ιδιότητα ChartCategoryCollection.UseCells.
