## SetExternalWorkbook(string) {#setexternalworkbook}

Ορίζει το εξωτερικό βιβλίο εργασίας ως πηγή δεδομένων για το διάγραμμα. Τα δεδομένα του διαγράμματος θα ενημερώνονται από το στοχευόμενο βιβλίο εργασίας.

```csharp
public void SetExternalWorkbook(string workbookPath)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| workbookPath | String | Διαδρομή προς το στοχευόμενο βιβλίο εργασίας |

### Εξαιρέσεις

| Εξαίρεση | Συνθήκη |
| --- | --- |
| InvalidOperationException | Το εξωτερικό βιβλίο εργασίας δεν είναι διαθέσιμο ή δεν μπορεί να φορτωθεί. |

### Παραδείγματα

```csharp
[C#]
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;
   (chartData as ChartData).SetExternalWorkbook("../../workbook.xlsx");

```

## SetExternalWorkbook(string, bool) {#setexternalworkbook_1}

Ορίζει το εξωτερικό βιβλίο εργασίας ως πηγή δεδομένων για το διάγραμμα.

```csharp
public void SetExternalWorkbook(string workbookPath, bool updateChartData)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| workbookPath | String | Διαδρομή προς το στοχευόμενο βιβλίο εργασίας |
| updateChartData | Boolean | Εάν η τιμή είναι false, θα ενημερώνεται μόνο η διαδρομή του βιβλίου εργασίας. Τα δεδομένα του διαγράμματος δεν θα φορτωθούν και δεν θα ενημερωθούν από το στοχευόμενο βιβλίο εργασίας. Μπορεί να χρησιμοποιηθεί όταν το στοχευόμενο βιβλίο εργασίας δεν υπάρχει ή δεν είναι διαθέσιμο. Εάν η τιμή είναι true, τα δεδομένα του διαγράμματος θα ενημερωθούν από το στοχευόμενο βιβλίο εργασίας. |

### Εξαιρέσεις

| Εξαίρεση | Συνθήκη |
| --- | --- |
| InvalidOperationException | Το εξωτερικό βιβλίο εργασίας δεν είναι διαθέσιμο ή δεν μπορεί να φορτωθεί. |

using (Presentation pres = new Presentation())
