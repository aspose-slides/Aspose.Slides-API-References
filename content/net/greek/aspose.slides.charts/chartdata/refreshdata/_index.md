## ChartData.RefreshData μέθοδος

Επαναφορτώνει τα δεδομένα του διαγράμματος φορτώνοντάς τα ξανά από το βιβλίο εργασίας προέλευσης.

```csharp
public void RefreshData()
```

### Εξαιρέσεις

| εξαίρεση | συνθήκη |
| --- | --- |
| InvalidOperationException | Εκδίδεται όταν η μορφή του βιβλίου εργασίας δεν υποστηρίζεται, ή όταν [`DataSourceType`](../datasourcetype) είναι ExternalWorkbook και το εξωτερικό βιβλίο εργασίας δεν μπορεί να προσπελαστεί ή να φορτωθεί. |

### Σχόλια

Εάν το διάγραμμα χρησιμοποιεί ένα εξωτερικό βιβλίο εργασίας, το βιβλίο εργασίας πρέπει να είναι προσβάσιμο τη στιγμή της κλήσης.

### Παραδείγματα

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
