## ChartCategory.UseCell propiedad

Si es true, la AsCell propiedad está activa. En otras palabras, la hoja de cálculo se usa para almacenar la categoría (este caso admite una categoría de varios niveles). Si es false, la AsLiteral propiedad está activa. En otras palabras, la hoja de cálculo NO se usa para almacenar la categoría (y este caso no admite categorías de varios niveles). Solo lectura Boolean.

```csharp
public bool UseCell { get; }
```

### Observaciones

Para cambiar el valor de esta propiedad (para todas las categorías en la colección) establezca el nuevo valor en la propiedad ChartCategoryCollection.UseCells.
