## IChartSeriesGroup.GapWidth propiedad

Obtiene o establece el espacio entre grupos de barras o columnas, como un porcentaje del ancho de la barra o columna. El valor debe estar entre 0 y 500. Lectura/escritura UInt16.

```csharp
public ushort GapWidth { get; set; }
```

### Observaciones

Esta propiedad se aplica a series de los siguientes tipos: Todos los subtipos de barra y columna, BarOfPie, PieOfPie, BoxAndWhisker, Funnel, Histogram, Waterfall.
