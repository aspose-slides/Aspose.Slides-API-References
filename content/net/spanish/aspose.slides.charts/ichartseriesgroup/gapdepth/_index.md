## IChartSeriesGroup.GapDepth propiedad

Obtiene o establece la distancia entre series de datos en un gráfico 3D, como un porcentaje del ancho del marcador. El valor debe estar entre 0 y 500. Lectura/escritura UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### Observaciones

Esta propiedad se aplica a series de los siguientes tipos: subtipos de barra y columna 3D, Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
