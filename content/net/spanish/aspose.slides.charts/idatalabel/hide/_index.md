## IDataLabel.Hide método

Oculta la etiqueta de datos estableciendo todas las banderas Show*-flags (ShowValue, ...) en estado false. IsVisible será false después de esto.

```csharp
public void Hide()
```

### Observaciones

Si la etiqueta de datos no es visible (IsVisible es false) puedes hacer que la etiqueta de datos sea visible estableciendo las banderas Show*-flags (ShowValue, ...) en estado true.
