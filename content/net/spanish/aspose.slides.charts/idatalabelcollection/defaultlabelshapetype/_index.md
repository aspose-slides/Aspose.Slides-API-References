## IDataLabelCollection.DefaultLabelShapeType propiedad

Obtiene o establece el tipo de forma predeterminado para las etiquetas de datos. Devuelve NotDefined si no se ha definido ninguna forma.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Observaciones

Establecer esta propiedad también asigna la propiedad [`LabelShapeType`](../../idatalabel/labelshapetype) para todas las etiquetas de datos en la colección al mismo valor.

### Ejemplos

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Establece el tipo de forma de todas las etiquetas de datos en la primera serie a Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
