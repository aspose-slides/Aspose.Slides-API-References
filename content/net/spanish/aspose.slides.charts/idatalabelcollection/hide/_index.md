## IDataLabelCollection.Hide método

Oculta la etiqueta de datos por defecto estableciendo todas las banderas Show*- (ShowValue, ...) de la propiedad DefaultDataLabelFormat en estado false. IsVisible será false después de esto.

```csharp
public void Hide()
```

### Observaciones

Si la etiqueta de datos no es visible por defecto (IsVisible es false) puedes hacer que la etiqueta de datos "visible por defecto" configurando las banderas Show*- (ShowValue, ...) de la propiedad DefaultDataLabelFormat en estado true.
