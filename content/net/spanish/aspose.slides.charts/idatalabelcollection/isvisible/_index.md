## IDataLabelCollection.IsVisible propiedad

False significa que la etiqueta de datos no es visible por defecto (y por lo tanto todas las banderas Show*- (ShowValue, ...) de la propiedad DefaultDataLabelFormat son false). Boolean de solo lectura.

```csharp
public bool IsVisible { get; }
```

### Observaciones

Si la etiqueta de datos es visible por defecto, puedes ocultarla por defecto con el método Hide(). Pero si la etiqueta de datos no es visible por defecto (IsVisible es false) puedes hacer que la etiqueta de datos "visible por defecto" configurando las banderas Show*- (ShowValue, ...) de la propiedad DefaultDataLabelFormat al estado true.
