## IChartData.RefreshData método

Actualiza los datos del gráfico recargando desde el libro de trabajo de origen.

```csharp
public void RefreshData()
```

### Excepciones

| excepción | condición |
| --- | --- |
| InvalidOperationException | Lanzada cuando el formato del libro de trabajo no es compatible, o cuando [`DataSourceType`](../datasourcetype) es ExternalWorkbook y el libro de trabajo externo no se puede acceder o cargar. |

### Observaciones

Si el gráfico utiliza un libro de trabajo externo, el libro de trabajo debe estar accesible en el momento de la llamada.

### Ejemplos

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
