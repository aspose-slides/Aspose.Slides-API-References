## FontsManager.GetFontBytes método

Recupera el array de bytes que representa los datos de fuente para un estilo de fuente y datos de fuente especificados.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| fontData | IFontData | El objeto de datos de fuente que contiene la información sobre la fuente [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | El estilo de la fuente para el cual se deben recuperar los datos [`FontStyleType`](../../fontstyletype). |

### Valor de retorno

Un array de bytes que contiene los datos de fuente para el estilo de fuente especificado. Si los datos de fuente o el estilo no se encuentran, devuelve null.

### Ejemplos

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // Recupera todas las fuentes utilizadas en la presentación
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Obtiene el array de bytes que representa el estilo regular de la primera fuente en la presentación
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
