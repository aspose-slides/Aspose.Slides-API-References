## FontsManager.PreferRegisteredFontsOverEmbedded propiedad

Especifica si se deben preferir las fuentes registradas sobre las fuentes incrustadas con el mismo nombre y estilo de fuente. Cuando está habilitado, las fuentes incrustadas coincidentes se reemplazan temporalmente por las fuentes registradas correspondientes durante la exportación.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Observaciones

El valor predeterminado es **false**.

### Ejemplos

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
