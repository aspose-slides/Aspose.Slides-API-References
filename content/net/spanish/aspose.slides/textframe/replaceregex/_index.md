## TextFrame.ReplaceRegex método

Reemplaza todas las coincidencias de la expresión regular con la cadena especificada.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| regex | Regex | La expresión regular Regex para obtener las cadenas que serán reemplazadas. |
| newText | String | La cadena para reemplazar todas las ocurrencias de las cadenas que serán reemplazadas. |
| callback | IFindResultCallback | Objeto de devolución de llamada para guardar el resultado de la operación de reemplazo [`IFindResultCallback`](../../ifindresultcallback). |

### Ejemplos

El siguiente código de muestra muestra cómo reemplazar texto usando expresiones regulares con la cadena especificada.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Reemplaza todas las palabras con 10 o más caracteres con '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
