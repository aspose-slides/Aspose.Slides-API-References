## IVideoFrame.VolumeValue propiedad

Devuelve o establece el volumen exacto del video como un porcentaje. El valor se expresa como un porcentaje de 0 a 100. Utilice esta propiedad para leer o establecer valores de volumen que sean más precisos que los niveles predefinidos disponibles a través del [`Volume`](../volume) propiedad. Lectura/escritura Single.

```csharp
public float VolumeValue { get; set; }
```

### Ejemplos

Ejemplo:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Lea el volumen exacto actual y establézcalo al 75,5 por ciento.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
