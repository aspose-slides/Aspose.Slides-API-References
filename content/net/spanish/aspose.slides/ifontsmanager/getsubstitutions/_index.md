## GetSubstitutions() {#getsubstitutions}

Obtiene la información sobre las fuentes que se reemplazarán durante la renderización de la presentación.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions()
```

### Valor de retorno

Colección de todas las sustituciones de fuentes [`FontSubstitutionInfo`](../../fontsubstitutioninfo).

### Ejemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions())
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}        
```

## GetSubstitutions(int[]) {#getsubstitutions_1}

Obtiene la información sobre las fuentes que se reemplazarán durante la renderización de las diapositivas especificadas.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| slides | Int32[] | Una matriz de índices de diapositivas para los que recuperar la información de sustitución de fuentes, comenzando desde 1. |

### Valor de retorno

Una colección de todas las sustituciones de fuentes ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) para las diapositivas especificadas.

### Ejemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
