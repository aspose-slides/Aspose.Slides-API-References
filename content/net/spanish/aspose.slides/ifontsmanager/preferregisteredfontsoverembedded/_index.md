## IFontsManager.PreferRegisteredFontsOverEmbedded propiedad

Especifica si las fuentes registradas deben tener preferencia sobre las fuentes incrustadas con el mismo nombre y estilo de fuente. Cuando está habilitado, las fuentes incrustadas coincidentes se sustituyen temporalmente por las fuentes registradas correspondientes durante la exportación.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Observaciones

El valor predeterminado es **false**.

### Ejemplos

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
