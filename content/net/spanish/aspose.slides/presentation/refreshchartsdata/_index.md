## Presentation.RefreshChartsData método

Recarga los datos de todos los gráficos en la presentación a partir de sus libros de trabajo de origen.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| skipFailedCharts | Boolean | Determina si el proceso de actualización continúa cuando un gráfico falla al actualizarse. Si `true`, los gráficos que generan una excepción se omiten; de lo contrario, la excepción se propaga. |

### Ejemplos

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
