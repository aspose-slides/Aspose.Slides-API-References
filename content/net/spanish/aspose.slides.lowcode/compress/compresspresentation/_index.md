## Método Compress.CompressPresentation

Reduce el tamaño de una presentación aplicando todos los pasos de compresión disponibles:

* Elimina diapositivas master no utilizadas [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Elimina diapositivas de diseño no utilizadas [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Mantiene solo los glifos realmente utilizados en fuentes incrustadas [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Reduce la resolución de imágenes a 150 DPI y elimina áreas recortadas de las imágenes [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| presentation | Presentation | La presentación a comprimir. |

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentNullException | *presentation* es `null`. |

### Observaciones

Para personalizar la compresión, por ejemplo para usar una resolución de imagen diferente o para omitir un paso, llame a los métodos listados arriba individualmente en lugar de este. Las áreas recortadas de las imágenes se eliminan de forma permanente y no pueden restaurarse en PowerPoint.

### Ejemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
