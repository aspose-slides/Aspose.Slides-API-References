## Compress.CompressImages método

Reduce la resolución de las imágenes en la presentación y elimina sus áreas recortadas, de forma similar a la función "Compress Pictures" de PowerPoint aplicada a todas las imágenes. Se procesan imágenes en diapositivas, diapositivas de diseño y diapositivas maestras, incluidas las imágenes dentro de formas agrupadas y los rellenos de imágenes de las formas.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| presentation | IPresentation | La presentación a procesar. |
| resolution | PicturesCompression | Resolución objetivo relativa al tamaño con el que se muestra cada imagen. DocumentResolution deja las imágenes sin cambios. |

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentNullException | *presentation* es `null`. |

### Observaciones

Las imágenes que ya están en la resolución objetivo o por debajo de ella se dejan sin cambios; las imágenes nunca se aumentan de escala.

No se procesan: fondos de diapositivas, rellenos de celdas de tabla, gráficos, SmartArt, imágenes GIF (para preservar la animación), imágenes SVG y metafiles (EMF/WMF).

Las áreas recortadas se eliminan permanentemente y no pueden restaurarse en PowerPoint.

### Ejemplos

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
