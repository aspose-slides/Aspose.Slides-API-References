## TextFrame.ReplaceText phương thức

Thay thế tất cả các lần xuất hiện của văn bản được chỉ định bằng một văn bản khác được chỉ định.

```csharp
public void ReplaceText(string oldText, string newText, ITextSearchOptions options, 
    IFindResultCallback callback)
```

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| oldText | String | Chuỗi cần được thay thế. |
| newText | String | Chuỗi sẽ thay thế mọi lần xuất hiện của oldText. |
| options | ITextSearchOptions | Các tùy chọn tìm kiếm văn bản [`ITextSearchOptions`](../../itextsearchoptions). |
| callback | IFindResultCallback | Đối tượng Callback để lưu kết quả hoạt động thay thế [`IFindResultCallback`](../../ifindresultcallback). |

### Ví dụ

Mã mẫu sau đây cho thấy cách thay thế một chuỗi được chỉ định bằng một chuỗi khác được chỉ định.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	// Thay thế tất cả các lần xuất hiện riêng biệt của 'the' bằng '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceText("the", "***", new TextSearchOptions()
	{ WholeWordsOnly = true }, null);
	presentation.Save("SomePresentation-out2.pptx", SaveFormat.Pptx);
}
```
