## ITextFrame.ReplaceRegex phương thức

Thay thế tất cả các khớp của biểu thức chính quy bằng chuỗi được chỉ định.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| regex | Regex | Biểu thức chính quy Regex để lấy các chuỗi cần thay thế. |
| newText | String | Chuỗi để thay thế tất cả các lần xuất hiện của các chuỗi cần được thay thế. |
| callback | IFindResultCallback | Đối tượng callback để nhận kết quả tìm kiếm [`IFindResultCallback`](../../ifindresultcallback). |

### Ví dụ

Mẫu mã dưới đây cho thấy cách thay thế văn bản bằng biểu thức chính quy với chuỗi được chỉ định.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Thay thế tất cả các từ có độ dài 10 ký tự trở lên bằng '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
