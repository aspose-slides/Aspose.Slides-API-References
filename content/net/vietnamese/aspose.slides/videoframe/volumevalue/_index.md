## VideoFrame.VolumeValue thuộc tính

Trả về hoặc đặt mức âm lượng video chính xác dưới dạng phần trăm. Giá trị được biểu thị dưới dạng phần trăm từ 0 đến 100. Sử dụng thuộc tính này để đọc hoặc đặt các giá trị âm lượng có độ chính xác cao hơn so với các mức cố định có sẵn qua thuộc tính [`Volume`](../volume). Đọc/ghi Single.

```csharp
public float VolumeValue { get; set; }
```

### Ví dụ

Example:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Đọc âm lượng chính xác hiện tại và đặt nó thành 75,5 phần trăm.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
