## FontsManager.PreferRegisteredFontsOverEmbedded thuộc tính

Xác định liệu các phông chữ đã đăng ký có nên được ưu tiên hơn các phông chữ nhúng có cùng tên và kiểu không. Khi bật, các phông chữ nhúng khớp sẽ tạm thời được thay thế bằng các phông chữ đã đăng ký tương ứng trong quá trình xuất.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Ghi chú

Mặc định là **false**.

### Ví dụ

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
