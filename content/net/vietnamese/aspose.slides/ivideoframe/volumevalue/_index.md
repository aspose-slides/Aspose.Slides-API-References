## IVideoFrame.VolumeValue thuộc tính

Trả về hoặc thiết lập mức âm lượng video chính xác dưới dạng phần trăm. Giá trị được biểu diễn dưới dạng phần trăm từ 0 đến 100. Sử dụng thuộc tính này để đọc hoặc thiết lập các giá trị âm lượng chính xác hơn so với các mức định trước có sẵn qua thuộc tính [`Volume`](../volume). Đọc/ghi Single.

```csharp
public float VolumeValue { get; set; }
```

### Ví dụ

Ví dụ:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Đọc mức âm lượng chính xác hiện tại và đặt nó thành 75.5 phần trăm.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
