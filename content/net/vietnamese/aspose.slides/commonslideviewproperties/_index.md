### Ví dụ

Ví dụ sau cho thấy cách thiết lập giá trị phóng to cho slide của PowerPoint Presentation.

```csharp
[C#]
// Khởi tạo một đối tượng Presentation đại diện cho tệp trình chiếu
using (Presentation presentation = new Presentation("demo.pptx"))
{
    // Đặt các thuộc tính chế độ xem của Presentation
    presentation.ViewProperties.SlideViewProperties.Scale = 100; // Giá trị phóng to tính bằng phần trăm cho chế độ xem slide
	presentation.ViewProperties.NotesViewProperties.Scale = 100; // Giá trị phóng to tính bằng phần trăm cho chế độ xem ghi chú
    presentation.Save("Zoom_out.pptx", SaveFormat.Pptx);
}
```
