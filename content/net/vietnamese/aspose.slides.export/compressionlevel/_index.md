## CompressionLevel liệt kê

Chỉ định các mức nén ZIP cho tệp OpenXML. Các mức cao hơn cung cấp độ nén tốt hơn nhưng tăng thời gian xử lý.

```csharp
public enum CompressionLevel
```

### Values

| Tên | Giá trị | Mô tả |
| --- | --- | --- |
| None | `0` | Không áp dụng nén. Các tệp được lưu nguyên như ban đầu. |
| Level1 | `1` | Nén nhanh nhất với tỷ lệ nén thấp nhất. |
| Level2 | `2` | Nén nhanh hơn với tỷ lệ nén hơi tốt hơn so với Level1. |
| Level3 | `3` | Cung cấp khả năng nén tốt hơn Level2 với ảnh hưởng hiệu năng trung bình. |
| Level4 | `4` | Cung cấp khả năng nén tốt hơn Level3. |
| Level5 | `5` | Cung cấp khả năng nén được cải thiện so với Level4 với thời gian xử lý bổ sung. |
| Level6 | `6` | Nén tiêu chuẩn, cung cấp sự cân bằng tốt giữa tốc độ nén và kích thước tệp. Mức nén mặc định. |
| Level7 | `7` | Cung cấp mức nén cao hơn Level6 với quá trình xử lý chậm hơn. |

| Level9 | `9` | Nén tối đa. Tạo kích thước tệp nhỏ nhất với tốc độ xử lý chậm nhất. |
