## IDataLabelCollection.DefaultLabelShapeType thuộc tính

Lấy hoặc đặt kiểu hình mặc định cho nhãn dữ liệu. Trả về NotDefined nếu không có hình nào được định nghĩa.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Ghi chú

Thiết lập thuộc tính này cũng sẽ thiết lập thuộc tính [`LabelShapeType`](../../idatalabel/labelshapetype) cho tất cả các nhãn dữ liệu trong bộ sưu tập có cùng giá trị.

### Ví dụ

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Đặt kiểu hình cho tất cả các nhãn dữ liệu trong series đầu tiên thành Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
