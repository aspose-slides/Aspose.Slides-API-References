## IChartDataPoint.CachedBubbleSize thuộc tính

Lấy kích thước bong bóng đã lưu trong bộ nhớ đệm của một điểm dữ liệu biểu đồ. Chỉ đọc [`ICachedChartValue`](../../icachedchartvalue).

```csharp
public ICachedChartValue CachedBubbleSize { get; }
```

### Ví dụ

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // In ra tất cả các giá trị kích thước bong bóng đã lưu trong bộ nhớ đệm của chuỗi biểu đồ.
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedBubbleSize.ToDouble());
    }
}
```
