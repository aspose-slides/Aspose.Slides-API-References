## IChartData.RefreshData phương thức

Làm mới dữ liệu biểu đồ bằng cách tải lại từ workbook nguồn.

```csharp
public void RefreshData()
```

### Ngoại lệ

| ngoại lệ | điều kiện |
| --- | --- |
| InvalidOperationException | Được ném khi định dạng workbook không được hỗ trợ, hoặc khi [`DataSourceType`](../datasourcetype) là ExternalWorkbook và workbook bên ngoài không thể truy cập hoặc tải. |

### Ghi chú

Nếu biểu đồ sử dụng workbook bên ngoài, workbook phải có thể truy cập tại thời điểm gọi.

### Ví dụ

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
