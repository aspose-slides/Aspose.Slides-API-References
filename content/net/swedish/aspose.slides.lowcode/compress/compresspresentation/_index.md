## Compress.CompressPresentation metod

Minskar storleken på en presentation genom att tillämpa alla tillgängliga komprimeringssteg:

* Tar bort oanvända masterbilder [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Tar bort oanvända layoutbilder [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Behåller endast de glyfer som faktiskt används i inbäddade typsnitt [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Minskar bildupplösningen till 150 DPI och tar bort beskurna områden i bilder [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| presentation | Presentation | Presentationen som ska komprimeras. |

### Undantag

| undantag | villkor |
| --- | --- |
| ArgumentNullException | *presentation* är `null`. |

### Anmärkningar

För att anpassa komprimeringen, till exempel för att använda en annan bildupplösning eller hoppa över ett steg, anropa metoderna som listas ovan individuellt istället för denna. Beskurna områden i bilder tas bort permanent och kan inte återställas i PowerPoint.

### Exempel

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
