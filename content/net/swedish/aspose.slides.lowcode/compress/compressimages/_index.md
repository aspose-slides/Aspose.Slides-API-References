## Compress.CompressImages metod

Minskar upplösningen på bilder i presentationen och tar bort deras beskurna områden, liknande PowerPoints "Compress Pictures" som tillämpas på alla bilder. Bilder på bildspel, layoutbilder och masternbilder bearbetas, inklusive bilder i gruppformer och bildfyllningar av former.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| presentation | IPresentation | Presentationen att bearbeta. |
| resolution | PicturesCompression | Måluppslösning relativt till storleken som varje bild visas i. DocumentResolution lämnar bilder oförändrade. |

### Undantag

| undantag | villkor |
| --- | --- |
| ArgumentNullException | *presentation* är `null`. |

### Anmärkningar

Bilder som redan har målupplösning eller lägre lämnas oförändrade; bilder skalas aldrig upp.

Ej bearbetade: bildbakgrunder, tabellcellfyllningar, diagram, SmartArt, GIF-bilder (för att bevara animation), SVG- och metafil- (EMF/WMF) bilder.

Beskurna områden tas bort permanent och kan inte återställas i PowerPoint.

### Exempel

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
