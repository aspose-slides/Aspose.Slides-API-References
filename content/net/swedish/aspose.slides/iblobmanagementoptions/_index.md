## IBlobManagementOptions gränssnitt

Ett Binary Large Object (BLOB) är binär data som lagras som en enda enhet – dvs. BLOB kan vara ett ljud, video eller en presentation i sig. Ett antal tekniker används för att optimera minnesförbrukningen när man arbetar med BLOB-objekt – som redan lagrats i presentationen eller kan läggas till senare programmässigt. Med [`IBlobManagementOptions`](../iblobmanagementoptions) kan du ändra olika beteendeaspekter kring BLOB-hantering för [`IPresentation`](../ipresentation)-instansens livstid.
