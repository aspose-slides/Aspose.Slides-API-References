## VideoFrame.VolumeValue egenskap

Returnerar eller anger den exakta videovolymen som en procentandel. Värdet uttrycks som en procentandel från 0 till 100. Använd denna egenskap för att läsa eller ange volymvärden som är mer exakta än de fördefinierade nivåerna som finns via [`Volume`](../volume) egenskap. Läs/skriv Single.

```csharp
public float VolumeValue { get; set; }
```

### Exempel

Exempel:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Läs den aktuella exakta volymen och sätt den till 75,5 procent.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
