### Exempel

Följande exempel visar hur man lägger till notes till en specifik ProwerPoint-presentation slide.

```csharp
[C#]
	// Instansierar ett Presentation-objekt som representerar en presentationsfil
	using(Presentation presentation = new Presentation(dataDir + "AccessSlides.pptx")) {
	  // Lägg till anteckningar på första bilden
	  INotesSlideManager mgr = presentation.Slides[0].NotesSlideManager;
	  INotesSlide noteSlide = mgr.AddNotesSlide();
	  noteSlide.NotesTextFrame.Text = "Your Notes";
	  // Spara presentationen till disk
	  presentation.Save(dataDir + "RemoveNotesAtSpecificSlide_out.pptx", SaveFormat.Pptx);
	}
```

Följande exempel visar hur man tar bort notes från en specifik slide i en PowerPoint-presentation.

```csharp
[C#]
	// Instansierar ett Presentation-objekt som representerar en presentationsfil
	using(Presentation presentation = new Presentation(dataDir + "AccessSlides.pptx")) {
	  // Tar bort anteckningar på första bilden
	  INotesSlideManager mgr = presentation.Slides[0].NotesSlideManager;
	  mgr.RemoveNotesSlide();
	  // Spara presentationen till disk
	  presentation.Save(dataDir + "RemoveNotesAtSpecificSlide_out.pptx", SaveFormat.Pptx);
	}
```
