## FontsManager.GetFontBytes metod

Hämtar bytearrayen som representerar teckensnittsdatan för en specificerad teckensnittsstil och teckensnittsdatan.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| fontData | IFontData | Teckensnittsdatenobjektet som innehåller informationen om teckensnittet [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | Stilen på teckensnittet för vilken datan ska hämtas [`FontStyleType`](../../fontstyletype). |

### Returvärde

En bytearray som innehåller teckensnittsdatan för den specificerade teckensnittsstilen. Om teckensnittsdatan eller stilen inte hittas, returneras null.

### Exempel

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // Hämta alla teckensnitt som används i presentationen
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Hämta bytearrayen som representerar den vanliga stilen för det första teckensnittet i presentationen
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
