## PresentationLockingBehavior uppräkning

Representerar beteendet för hur [`IPresentation`](../ipresentation)-källan (fil eller Stream) behandlas vid inläsning och arbete med en instans av [`IPresentation`](../ipresentation).

```csharp
public enum PresentationLockingBehavior
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| LoadAndRelease | `0` | Källan kommer endast att låsas under tiden för [`IPresentation`](../ipresentation)-konstruktorns exekvering. Om [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) är satt till false, laddas alla BLOB-objekt in i minnet. Annars kan andra metoder, såsom temporära filer, användas. Detta beteende är långsammare än KeepLocked, och om det är möjligt att överföra äganderätten för källan till [`IPresentation`](../ipresentation), rekommenderas det att använda KeepLocked. |
| KeepLocked | `1` | Källan kommer att låsas under hela livstiden för en [`IPresentation`](../ipresentation)-instans, tills den blir avyttrad. [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) måste vara satt till true för att använda detta beteende, annars kommer ett undantag att kastas. Detta beteende rekommenderas, det är snabbare och förbrukar mindre minne än LoadAndRelease. |

### Anmärkningar

Källan är den parameter som skickas till [`IPresentation`](../ipresentation)-konstruktorn. I exemplet nedan är källan filen "pres.pptx":

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

För detta exempel kommer källan (filen "pres.pptx") att låsas under en [`IPresentation`](../ipresentation)-instans livstid, dvs. kan inte ändras eller tas bort av en annan process.
