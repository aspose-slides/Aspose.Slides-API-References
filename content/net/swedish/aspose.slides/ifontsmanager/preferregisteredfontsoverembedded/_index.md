## IFontsManager.PreferRegisteredFontsOverEmbedded egenskap

Anger huruvida registrerade teckensnitt ska föredras framför inbäddade teckensnitt med samma teckensnittsnamn och stil. När den är aktiverad ersätts matchande inbäddade teckensnitt tillfälligt med motsvarande registrerade teckensnitt under export.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Anmärkningar

Standard är **false**.

### Exempel

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
