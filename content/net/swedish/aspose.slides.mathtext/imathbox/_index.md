## IMathBox gränssnitt

Anger den logiska inneslutningen (paketeringen) av ett matematiskt element. Till exempel kan ett inneslutet objekt fungera som en operatoremulator med eller utan en justeringspunkt, fungera som en radbrytningspunkt, eller grupperas så att radbrytningar inte tillåts inom det. Till exempel bör operatorn "==" inneslutas för att förhindra radbrytningar.

```csharp
public interface IMathBox : IMathElement
```
