## IMathPhantom gränssnitt

Representerar ett phantom-matematiktobjekt (&lt;m:phant&gt;) som påverkar layouten för sitt underordnade element utan att nödvändigtvis visas. En phantom kan dölja sitt basuttryck samtidigt som den bevarar sin bredd, höjd eller djup för att justera formler eller reservera utrymme. Synlighet och geometribeteende styrs av egenskaper som Show, ZeroWid, ZeroAsc, ZeroDesc och Transp.

```csharp
public interface IMathPhantom : IMathElement
```
