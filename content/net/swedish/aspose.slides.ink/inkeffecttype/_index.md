## InkEffectType enumeration

Anger en uppsättning fördefinierade visuella effekter för bläckåtergivning. Varje effekt motsvarar en textur eller bild som simulerar ett stiliserat bläckutseende. Dessa värden kan användas för att anpassa den visuella stilen på digitala bläckstreck under återgivning.

```csharp
public enum InkEffectType
```

### Values

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| NotDefined | `-1` | Effekten är inte definierad eller är okänd. Detta värde kan användas som standard eller reserv. |
| Bronze | `0` | En varm, brunaktig metallisk textur som liknar bronsbläck. |
| Galaxy | `1` | En färgstark, skimrande textur som liknar en galax, med kosmiska toner. |
| Gold | `2` | En ljus, metallisk guldfärgad textur som ger bläckstrecken ett lyxigt utseende. |
| Lava | `3` | En eldigt textur som liknar smält lava, med röda och orangea nyanser. |
| Ocean | `4` | En djupblå, flytande textur som efterliknar havsvågor eller vattenbaserat bläck. |
| RainbowGlitter | `5` | En färgstark, glittrande regnbågsskimrande effekt som används för festliga eller livfulla bläckstreck. |
| RoseGold | `6` | En mjuk rosa-guldblandning, liknande roséguld, för eleganta bläckstreck. |
| Silver | `7` | En kall, metallisk silvertextur som simulerar klassiskt silverbläck. |
