## Zip64Mode enumeration

Anger när ZIP64 format extensions ska användas för OpenXML-fil.

```csharp
public enum Zip64Mode
```

### Värden

| Name | Value | Description |
| --- | --- | --- |
| Never | `0` | Använd inte ZIP64 format extensions. |
| IfNecessary | `1` | Använd ZIP64 format extensions om det behövs. |
| Always | `2` | Använd alltid ZIP64 format extensions. |

### Anmärkningar

OpenXML-filen är ett ZIP-arkiv som har en gräns på 4 GB (2^32 byte) för okomprimerad filstorlek, komprimerad filstorlek och total arkivstorlek, samt en gräns på 65 535 (2^16-1) filer i arkivet. ZIP64 format extensions ökar gränserna till 2^64.
