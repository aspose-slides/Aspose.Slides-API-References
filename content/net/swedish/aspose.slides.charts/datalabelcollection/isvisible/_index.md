## DataLabelCollection.IsVisible egenskap

False betyder att dataetikett inte är synlig som standard (och så är alla Show*-flags (ShowValue, ...) för DefaultDataLabelFormat egenskap falska). Skrivskyddad Boolean.

```csharp
public bool IsVisible { get; }
```

### Anmärkningar

Om dataetikett är synlig som standard kan du göra den dold som standard med Hide() metod. Men om dataetikett inte är synlig som standard (IsVisible är false) kan du göra dataetikett "synlig som standard" genom att sätta Show*-flags (ShowValue, ...) för DefaultDataLabelFormat egenskap till true-tillstånd.
