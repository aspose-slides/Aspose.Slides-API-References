## IDataLabelCollection.DefaultLabelShapeType egenskap

Hämtar eller anger standardformtypen för dataetiketter. Returnerar NotDefined om ingen form är definierad.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Anmärkningar

Att ange denna egenskap sätter också egenskapen [`LabelShapeType`](../../idatalabel/labelshapetype) för alla dataetiketter i samlingen till samma värde.

### Exempel

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Ställ in formtypen för alla dataetiketter i den första serien till Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
