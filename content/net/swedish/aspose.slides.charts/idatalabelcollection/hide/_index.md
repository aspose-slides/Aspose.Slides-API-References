## IDataLabelCollection.Hide metod

Gör datamärket dolt som standard genom att sätta alla Show*-flaggor (ShowValue, ...) för DefaultDataLabelFormat egenskapen till falskt läge. IsVisible blir falskt efter detta.

```csharp
public void Hide()
```

### Anmärkningar

Om datamärket inte är synligt som standard (IsVisible är falskt) kan du göra datamärket "synligt som standard" genom att sätta Show*-flaggor (ShowValue, ...) för DefaultDataLabelFormat egenskapen till sant läge.
