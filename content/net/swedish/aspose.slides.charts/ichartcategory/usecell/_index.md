## IChartCategory.UseCell egenskap

Om true är egenskapen AsCell aktuell. Med andra ord används arbetsbladet för att lagra kategori (detta fall stöder en flernivåkategori). Om false är egenskapen AsLiteral aktuell. Med andra ord används arbetsbladet INTE för att lagra kategori (och detta fall stöder inte flernivåkategorier). Skrivskyddad Boolean.

```csharp
public bool UseCell { get; }
```

### Anmärkningar

För att ändra värdet på denna egenskap (för alla kategorier i samlingen) sätt det nya värdet till egenskapen ChartCategoryCollection.UseCells.
