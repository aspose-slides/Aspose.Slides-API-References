## SetExternalWorkbook(string) {#setexternalworkbook}

Ställer in extern arbetsbok som datakälla för diagrammet. Diagramdata kommer att uppdateras från målarbetsboken.

```csharp
public void SetExternalWorkbook(string workbookPath)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| workbookPath | String | Sökväg till målarbetsboken |

### Undantag

| undantag | villkor |
| --- | --- |
| InvalidOperationException | Extern arbetsbok är inte tillgänglig eller kan inte laddas. |

### Exempel

```csharp
[C#]
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;
   (chartData as ChartData).SetExternalWorkbook("../../workbook.xlsx");

```

## SetExternalWorkbook(string, bool) {#setexternalworkbook_1}

Ställer in extern arbetsbok som datakälla för diagrammet.

```csharp
public void SetExternalWorkbook(string workbookPath, bool updateChartData)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| workbookPath | String | Sökväg till målarbetsboken |
| updateChartData | Boolean | Om värdet är false uppdateras endast sökvägen till arbetsboken. Diagramdata kommer inte att laddas och uppdateras från målarbetsboken. Kan användas när målarboken inte finns eller inte är tillgänglig. Om värdet är true uppdateras diagramdata från målarboken. |

### Undantag

| undantag | villkor |
| --- | --- |
| InvalidOperationException | Extern arbetsbok är inte tillgänglig eller kan inte laddas. |

### Exempel

```csharp
using (Presentation pres = new Presentation())

   IChart chart = pres.Slides[0].Shapes.AddChart(ChartType.Pie, 50, 50, 400, 600, true);
   IChartData chartData = chart.ChartData;

   (chartData as ChartData).SetExternalWorkbook("http://path/doesnt/exists", false);


```
