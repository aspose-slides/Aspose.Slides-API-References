## IChartData.RefreshData metod

Uppdaterar diagramdata genom att läsa in den från källarboken.

```csharp
public void RefreshData()
```

### Undantag

| undantag | villkor |
| --- | --- |
| InvalidOperationException | Kastas när arbetsbokformatet inte stöds, eller när [`DataSourceType`](../datasourcetype) är ExternalWorkbook och den externa arbetsboken inte kan nås eller läsas in. |

### Anmärkningar

Om diagrammet använder en extern arbetsbok måste arbetsboken vara tillgänglig när metoden anropas.

### Exempel

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
