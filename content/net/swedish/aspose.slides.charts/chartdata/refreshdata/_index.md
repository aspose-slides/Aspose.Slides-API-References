## ChartData.RefreshData metod

Uppdaterar diagramdata genom att läsa in dem från källarbetsboken.

```csharp
public void RefreshData()
```

### Undantag

| undantag | villkor |
| --- | --- |
| InvalidOperationException | Kastas när arbetsboksformatet inte stöds, eller när [`DataSourceType`](../datasourcetype) är ExternalWorkbook och den externa arbetsboken inte kan nås eller laddas. |

### Anmärkningar

Om diagrammet använder en extern arbetsbok måste arbetsboken vara åtkomlig när metoden anropas.

### Exempel

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
