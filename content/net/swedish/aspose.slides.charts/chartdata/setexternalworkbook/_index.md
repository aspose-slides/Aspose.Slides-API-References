```csharp

```

| Parameter | Typ | Beskrivning |

| updateChartData | Boolean | Om värdet är false uppdateras endast arbetsbokens sökväg. Diagramdata laddas inte och uppdateras inte från målarbetsboken. Kan användas när målarbetsboken inte finns eller inte är tillgänglig. Om värdet är true uppdateras diagramdata från målarbetsboken. |
