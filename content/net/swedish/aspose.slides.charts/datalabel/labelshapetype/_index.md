## DataLabel.LabelShapeType egenskap

Hämtar eller anger formtypen för dataetiketten. Returnerar NotDefined om ingen form är definierad.

```csharp
public ShapeType LabelShapeType { get; set; }
```

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
```
