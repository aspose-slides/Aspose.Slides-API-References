## IVideoFrame.VolumeValue properti

Mengembalikan atau menetapkan volume video yang tepat sebagai persentase. Nilai diungkapkan sebagai persentase dari 0 hingga 100. Gunakan properti ini untuk membaca atau mengatur nilai volume yang lebih tepat daripada tingkat yang telah ditentukan tersedia melalui properti [`Volume`](../volume). Baca/tulis Single.

```csharp
public float VolumeValue { get; set; }
```

### Contoh

Contoh:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Baca volume tepat saat ini dan setel ke 75,5 persen.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
