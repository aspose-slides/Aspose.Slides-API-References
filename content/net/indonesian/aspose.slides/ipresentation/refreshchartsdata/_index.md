## IPresentation.RefreshChartsData metode

Memuat ulang data untuk semua diagram dalam presentasi dari buku kerja sumber.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| skipFailedCharts | Boolean | Menentukan apakah proses penyegaran akan dilanjutkan jika sebuah diagram gagal diperbarui. Jika `true`, diagram yang menyebabkan pengecualian akan dilewati; jika tidak, pengecualian akan diteruskan. |

### Contoh

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
