## IFontsManager.PreferRegisteredFontsOverEmbedded properti

Menentukan apakah font yang terdaftar harus dipilih alih-alih font yang disematkan dengan nama dan gaya font yang sama. Ketika diaktifkan, font yang disematkan yang cocok sementara diganti dengan font terdaftar yang sesuai selama proses ekspor.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Catatan

Default adalah **false**.

### Contoh

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
