## TextFrame.ReplaceRegex metode

Mengganti semua kecocokan ekspresi reguler dengan string yang ditentukan.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| regex | Regex | Ekspresi reguler Regex untuk mendapatkan string yang akan diganti. |
| newText | String | String untuk mengganti semua kejadian string yang akan diganti. |
| callback | IFindResultCallback | Objek callback untuk menyimpan hasil operasi penggantian [`IFindResultCallback`](../../ifindresultcallback). |

### Contoh

The following sample code shows how to replace text using regular expression with specified string.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Ganti semua kata dengan 10 atau lebih karakter dengan '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
