## DataLabelCollection.Hide metode

Buat label data tersembunyi secara default dengan mengatur semua flag Show*- (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan false. IsVisible akan menjadi false setelah ini.

```csharp
public void Hide()
```

### Catatan

Jika label data tidak terlihat secara default (IsVisible false) Anda dapat membuat label data "terlihat secara default" dengan mengatur flag Show*- (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan true.
