## DataLabelCollection.DefaultLabelShapeType properti

Mendapatkan atau menetapkan tipe bentuk default untuk label data. Mengembalikan NotDefined jika tidak ada bentuk yang didefinisikan.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Keterangan

Mengatur properti ini juga mengatur properti [`LabelShapeType`](../../idatalabel/labelshapetype) untuk semua label data dalam koleksi ke nilai yang sama.

### Contoh

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Tetapkan tipe bentuk semua label data pada seri pertama menjadi Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
