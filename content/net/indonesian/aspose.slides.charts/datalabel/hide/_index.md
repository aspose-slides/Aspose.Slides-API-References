## DataLabel.Hide metode

Buat label data disembunyikan dengan mengatur semua Show*-flags (ShowValue, ...) ke keadaan false. IsVisible akan menjadi false setelah ini.

```csharp
public void Hide()
```

### Catatan

Jika label data tidak terlihat (IsVisible adalah false) Anda dapat membuat label data terlihat dengan mengatur Show*-flags (ShowValue, ...) ke keadaan true.
