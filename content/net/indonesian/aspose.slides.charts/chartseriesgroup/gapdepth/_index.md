## ChartSeriesGroup.GapDepth properti

Mendapatkan atau menetapkan jarak antara seri data dalam grafik 3D, sebagai persentase lebar penanda. Nilainya harus antara 0 dan 500. Baca/tulis UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### Catatan

Properti ini berlaku untuk seri dengan tipe berikut: subtipe bar dan kolom 3D (lihat juga metode [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart)), Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
