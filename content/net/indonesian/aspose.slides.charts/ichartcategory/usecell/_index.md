## IChartCategory.UseCell properti

Jika true maka properti AsCell yang berlaku. Dengan kata lain, worksheet digunakan untuk menyimpan kategori (kasus ini mendukung kategori multi-level). Jika false maka properti AsLiteral yang berlaku. Dengan kata lain, worksheet TIDAK digunakan untuk menyimpan kategori (dan kasus ini tidak mendukung kategori multi-level). Boolean baca-saja.

```csharp
public bool UseCell { get; }
```

### Keterangan

Untuk mengubah nilai properti ini (untuk semua kategori dalam koleksi) tetapkan nilai baru ke properti ChartCategoryCollection.UseCells.
