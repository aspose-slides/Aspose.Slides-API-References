## ChartCategory.UseCell properti

Jika bernilai true maka properti AsCell berlaku. Dengan kata lain, lembar kerja digunakan untuk menyimpan kategori (kasus ini mendukung kategori multi-tingkat). Jika bernilai false maka properti AsLiteral berlaku. Dengan kata lain, lembar kerja TIDAK digunakan untuk menyimpan kategori (dan kasus ini tidak mendukung kategori multi-tingkat). Boolean baca-saja.

```csharp
public bool UseCell { get; }
```

### Catatan

Untuk mengubah nilai properti ini (untuk semua kategori dalam koleksi) setel nilai baru ke properti ChartCategoryCollection.UseCells.
