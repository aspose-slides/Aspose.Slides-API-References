## IDataLabelCollection.IsVisible properti

False berarti bahwa data label tidak terlihat secara default (dan sehingga semua Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat bernilai false). Boolean hanya-baca.

```csharp
public bool IsVisible { get; }
```

### Catatan

Jika data label terlihat secara default, Anda dapat menyembunyikannya secara default dengan metode Hide(). Namun jika data label tidak terlihat secara default (IsVisible bernilai false), Anda dapat membuat data label "terlihat secara default" dengan mengatur Show*-flags (ShowValue, ...) dari properti DefaultDataLabelFormat ke keadaan true.
