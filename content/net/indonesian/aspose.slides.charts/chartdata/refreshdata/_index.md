## ChartData.RefreshData method

Menyegarkan data diagram dengan memuat ulangnya dari buku kerja sumber.

```csharp
public void RefreshData()
```

### Pengecualian

| pengecualian | kondisi |
| --- | --- |
| InvalidOperationException | Dilempar ketika format buku kerja tidak didukung, atau ketika [`DataSourceType`](../datasourcetype) adalah ExternalWorkbook dan buku kerja eksternal tidak dapat diakses atau dimuat. |

### Catatan

Jika diagram menggunakan buku kerja eksternal, buku kerja harus dapat diakses pada saat pemanggilan.

### Contoh

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
