## ChartData.SetRange metode

Atur rentang data diagram. Seri dan kategori akan diperbarui berdasarkan rentang data baru. Jika jumlah seri dalam rentang data lebih besar daripada jumlah seri dalam data diagram maka seri tambahan dengan tipe yang sama dengan seri terakhir dalam koleksi saat ini akan ditambahkan ke akhir koleksi.

```csharp
public void SetRange(string formula)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| formula | String | Rumus rentang data sel. Misalnya: "Sheet1!$A$1:$C$4" , "SomeSheetName!A1:B100", "Sheet1!$A$1:$B$5;Sheet1!$D$1:$D$5". |

### Pengecualian

| pengecualian | kondisi |
| --- | --- |
| ArgumentNullException | formula bernilai null. |
| InvalidOperationException | Tipe diagram tidak didukung |
| ArgumentException | formula memiliki format yang tidak benar. |
