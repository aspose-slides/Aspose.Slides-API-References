## IDataLabel.LabelShapeType properti

Mendapatkan atau mengatur tipe bentuk label data. Mengembalikan NotDefined jika tidak ada bentuk yang ditentukan.

```csharp
public ShapeType LabelShapeType { get; set; }
```

### Contoh

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
```
