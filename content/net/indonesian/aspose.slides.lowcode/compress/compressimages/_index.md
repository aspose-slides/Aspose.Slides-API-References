## Compress.CompressImages metode

Mengurangi resolusi gambar dalam presentasi dan menghapus area terpotongnya, mirip dengan "Compress Pictures" di PowerPoint yang diterapkan pada semua gambar. Gambar pada slide, slide tata letak, dan slide master diproses, termasuk gambar di dalam grup bentuk dan isian gambar pada bentuk.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| presentation | IPresentation | presentation yang diproses. |
| resolution | PicturesCompression | Resolusi target relatif terhadap ukuran saat setiap gambar ditampilkan. DocumentResolution tidak mengubah gambar. |

### Pengecualian

| pengecualian | kondisi |
| --- | --- |
| ArgumentNullException | *presentation* adalah `null`. |

### Catatan

Gambar yang sudah pada atau di bawah resolusi target dibiarkan tidak berubah; gambar tidak pernah ditingkatkan skalanya.

Tidak diproses: latar belakang slide, isi sel tabel, diagram, SmartArt, gambar GIF (untuk mempertahankan animasi), gambar SVG dan metafile (EMF/WMF).

Area yang dipotong dihapus secara permanen dan tidak dapat dipulihkan di PowerPoint.

### Contoh

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
