## IDataLabelCollection.DefaultLabelShapeType คุณสมบัติ

รับหรือกำหนดค่าประเภทรูปร่างเริ่มต้นสำหรับป้ายข้อมูล. คืนค่า NotDefined หากไม่มีรูปร่างถูกกำหนด.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### หมายเหตุ

การตั้งค่าคุณสมบัตินี้ยังตั้งค่าคุณสมบัติ [`LabelShapeType`](../../idatalabel/labelshapetype) สำหรับป้ายข้อมูลทั้งหมดในคอลเลกชันเป็นค่าเดียวกัน.

### ตัวอย่าง

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // ตั้งค่าประเภทรูปร่างของป้ายข้อมูลทั้งหมดในซีรีส์แรกเป็น Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
