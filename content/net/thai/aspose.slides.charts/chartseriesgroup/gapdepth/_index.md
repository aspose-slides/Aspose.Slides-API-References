## ChartSeriesGroup.GapDepth คุณสมบัติ

รับหรือกำหนดระยะห่างระหว่างชุดข้อมูลในแผนภูมิ 3 มิติ ในรูปของเปอร์เซ็นต์ของความกว้างของเครื่องหมาย. ค่าต้องอยู่ระหว่าง 0 ถึง 500. อ่าน/เขียน UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### หมายเหตุ

คุณสมบัตินี้ใช้กับชุดข้อมูลของประเภทต่อไปนี้: ชนิดย่อย 3D แท่งและคอลัมน์ (ดูเพิ่มเติม [`IsBar3DChart`](../../charttypecharacterizer/isbar3dchart) เมธอด), Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
