## IChartData.RefreshData method

รีเฟรชข้อมูลแผนภูมิโดยโหลดใหม่จากเวิร์กบุ๊กต้นทาง

```csharp
public void RefreshData()
```

### Exceptions

| ข้อยกเว้น | เงื่อนไข |
| --- | --- |
| InvalidOperationException | เกิดเมื่อรูปแบบเวิร์กบุ๊กไม่รองรับ หรือเมื่อ [`DataSourceType`](../datasourcetype) เป็น ExternalWorkbook และไม่สามารถเข้าถึงหรือโหลดเวิร์กบุ๊กภายนอกได้. |

### Remarks

หากแผนภูมิใช้เวิร์กบุ๊กภายนอก เวิร์กบุ๊กต้องสามารถเข้าถึงได้ในขณะที่เรียกใช้.

### Examples

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
