## ChartData.RefreshData เมธอด

รีเฟรชข้อมูลแผนภูมิโดยโหลดใหม่จากเวิร์กบุ๊คต้นทาง.

```csharp
public void RefreshData()
```

### ข้อยกเว้น

| ข้อยกเว้น | เงื่อนไข |
| --- | --- |
| InvalidOperationException | เกิดข้อยกเว้นเมื่อรูปแบบของเวิร์กบุ๊คไม่รองรับ หรือเมื่อ [`DataSourceType`](../datasourcetype) เป็น ExternalWorkbook และไม่สามารถเข้าถึงหรือโหลดเวิร์กบุ๊คภายนอกได้. |

### หมายเหตุ

หากแผนภูมิใช้เวิร์กบุ๊คภายนอก เวิร์กบุ๊คต้องสามารถเข้าถึงได้ในเวลาที่เรียกใช้.

### ตัวอย่าง

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
