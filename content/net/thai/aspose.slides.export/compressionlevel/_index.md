## CompressionLevel enum

ระบุระดับการบีบอัด ZIP สำหรับไฟล์ OpenXML ระดับที่สูงกว่าจะให้การบีบอัดที่ดีกว่าแต่มีค่าใช้จ่ายเป็นการประมวลผลที่ช้าลง.

```csharp
public enum CompressionLevel
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| None | `0` | ไม่มีการบีบอัดใด ๆ ไฟล์จะถูกเก็บไว้ตามเดิม. |
| Level1 | `1` | การบีบอัดที่เร็วที่สุดโดยมีอัตราการบีบอัดต่ำสุด. |
| Level2 | `2` | การบีบอัดที่เร็วขึ้นโดยอัตราการบีบอัดที่ดีกว่า Level1 เล็กน้อย. |
| Level3 | `3` | ให้การบีบอัดที่ดีกว่า Level2 โดยมีผลต่อประสิทธิภาพระดับปานกลาง. |
| Level4 | `4` | ให้การบีบอัดที่ดีกว่า Level3. |
| Level5 | `5` | ให้การบีบอัดที่ดีขึ้นกว่า Level4 พร้อมกับเวลาการประมวลผลที่เพิ่มขึ้น. |
| Level6 | `6` | การบีบอัดมาตรฐาน ให้ความสมดุลที่ดีระหว่างความเร็วในการบีบอัดและขนาดไฟล์. ระดับการบีบอัดเริ่มต้น. |
| Level7 | `7` | ให้การบีบอัดสูงกว่า Level6 โดยมีการประมวลผลที่ช้าลง. |
| Level8 | `8` | ให้การบีบอัดสูงกว่า Level7. |
| Level9 | `9` | การบีบอัดสูงสุด ผลิตไฟล์ที่มีขนาดเล็กที่สุดด้วยความเร็วการประมวลผลที่ช้าที่สุด. |
