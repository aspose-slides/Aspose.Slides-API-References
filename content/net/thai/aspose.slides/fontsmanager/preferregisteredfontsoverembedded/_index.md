## FontsManager.PreferRegisteredFontsOverEmbedded คุณสมบัติ

ระบุว่าจะให้ฟอนต์ที่ลงทะเบียนเป็นค่าเริ่มต้นเหนือฟอนต์แบบฝังที่มีชื่อและสไตล์เดียวกันหรือไม่ เมื่อเปิดใช้งาน ฟอนต์แบบฝังที่ตรงกันจะถูกแทนที่ชั่วคราวด้วยฟอนต์ที่ลงทะเบียนที่สอดคล้องกันในระหว่างการส่งออก

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### หมายเหตุ

ค่าเริ่มต้นคือ **false**.

### ตัวอย่าง

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
