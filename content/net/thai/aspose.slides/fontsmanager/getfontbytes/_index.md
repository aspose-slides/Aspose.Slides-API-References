## FontsManager.GetFontBytes เมธอด

ดึงอาเรย์ของไบต์ที่แสดงถึงข้อมูลแบบอักษรสำหรับสไตล์แบบอักษรและข้อมูลแบบอักษรที่ระบุ

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| fontData | IFontData | อ็อบเจ็กต์ข้อมูลแบบอักษรที่มีข้อมูลเกี่ยวกับแบบอักษร [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | สไตล์ของแบบอักษรที่ต้องการดึงข้อมูล [`FontStyleType`](../../fontstyletype). |

### ค่าที่ส่งกลับ

อาเรย์ของไบต์ที่มีข้อมูลแบบอักษรสำหรับสไตล์แบบอักษรที่ระบุ หากไม่พบข้อมูลแบบอักษรหรือสไตล์ จะคืนค่า null

### ตัวอย่าง

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // ดึงแบบอักษรทั้งหมดที่ใช้ในงานนำเสนอ
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // รับอาเรย์ของไบต์ที่แสดงถึงสไตล์ปกติของแบบอักษรแรกในงานนำเสนอ
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
