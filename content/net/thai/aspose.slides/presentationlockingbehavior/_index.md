## PresentationLockingBehavior รายการ

แสดงพฤติกรรมเกี่ยวกับการจัดการแหล่งข้อมูล [`IPresentation`](../ipresentation) (ไฟล์หรือ Stream) ในขณะโหลดและทำงานกับอินสแตนซ์ของ [`IPresentation`](../ipresentation).

```csharp
public enum PresentationLockingBehavior
```

### ค่า

| ชื่อ | ค่า | รายละเอียด |
| --- | --- | --- |
| LoadAndRelease | `0` | แหล่งข้อมูลจะถูกล็อคเฉพาะในช่วงเวลาที่ตัวสร้าง [`IPresentation`](../ipresentation) ทำงาน หาก [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) ถูกตั้งค่าเป็น false, BLOB ทั้งหมดจะถูกโหลดเข้าไปในหน่วยความจำ มิฉะนั้น อาจใช้วิธีอื่นเช่นไฟล์ชั่วคราว พฤติกรรมนี้ช้ากว่า KeepLocked และหากสามารถโอนความเป็นเจ้าของของแหล่งข้อมูลให้กับ [`IPresentation`](../ipresentation) ได้ แนะนำให้ใช้ KeepLocked. |
| KeepLocked | `1` | แหล่งข้อมูลจะถูกล็อคตลอดอายุการใช้งานของอินสแตนซ์ [`IPresentation`](../ipresentation) จนกว่าจะถูกทำลาย [`IsTemporaryFilesAllowed`](../iblobmanagementoptions/istemporaryfilesallowed) ต้องตั้งค่าเป็น true เพื่อใช้พฤติกรรมนี้ มิฉะนั้นจะเกิดข้อยกเว้น พฤติกรรมนี้แนะนำ เนื่องจากเร็วกว่าและใช้หน่วยความจำน้อยกว่า LoadAndRelease. |

### หมายเหตุ

แหล่งข้อมูลเป็นพารามิเตอร์ที่ส่งให้กับตัวสร้าง [`IPresentation`](../ipresentation) ในตัวอย่างด้านล่าง แหล่งข้อมูลคือไฟล์ "pres.pptx" :

```csharp
LoadOptions loadOptions = new LoadOptions { 
  BlobManagementOptions = { PresentationLockingBehavior = PresentationLockingBehavior.KeepLocked } };
using (IPresentation pres = new Presentation("pres.pptx", loadOptions)) { }
```

สำหรับตัวอย่างนี้ แหล่งข้อมูล (ไฟล์ "pres.pptx") จะถูกล็อคตลอดอายุการใช้งานของอินสแตนซ์ [`IPresentation`](../ipresentation) ซึ่งหมายความว่าจะไม่สามารถเปลี่ยนแปลงหรือทำการลบโดยกระบวนการอื่นได้.
