## IPresentation.RefreshChartsData เมธอด

โหลดข้อมูลสำหรับแผนภูมิทั้งหมดในงานนำเสนอจากสมุดงานต้นทางของพวกมัน

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| skipFailedCharts | Boolean | กำหนดว่ากระบวนการรีเฟรชจะดำเนินต่อไปหรือไม่หากแผนภูมิไม่สามารถอัปเดตได้ หาก `true` แผนภูมิที่ทำให้เกิดข้อยกเว้นจะถูกข้าม; มิฉะนั้นข้อยกเว้นจะถูกส่งต่อ |

### ตัวอย่าง

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
