## IVideoFrame.VolumeValue คุณสมบัติ

คืนค่า หรือกำหนดระดับเสียงวิดีโอที่แม่นยำเป็นเปอร์เซ็นต์. ค่าถูกแสดงเป็นเปอร์เซ็นต์ตั้งแต่ 0 ถึง 100. ใช้คุณสมบัตินี้เพื่ออ่านหรือกำหนดค่าระดับเสียงที่แม่นยำกว่าระดับที่กำหนดไว้ล่วงหน้าผ่านคุณสมบัติ [`Volume`](../volume). อ่าน/เขียน Single.

```csharp
public float VolumeValue { get; set; }
```

### ตัวอย่าง

ตัวอย่าง:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // อ่านระดับเสียงที่แม่นยำปัจจุบันและตั้งค่าเป็น 75.5 เปอร์เซ็นต์.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
