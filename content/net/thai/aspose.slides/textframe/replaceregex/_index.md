## TextFrame.ReplaceRegex เมธอด

แทนที่ทั้งหมดของการจับคู่ของ regular expression ด้วยสตริงที่ระบุ.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | regular expression Regex ที่ใช้เพื่อดึงสตริงที่ต้องการแทนที่. |
| newText | String | สตริงที่ใช้แทนที่ occurrence ทั้งหมดของสตริงที่ต้องการแทนที่. |
| callback | IFindResultCallback | อ็อบเจ็กต์ Callback สำหรับบันทึกผลการดำเนินการแทนที่ [`IFindResultCallback`](../../ifindresultcallback). |

### ตัวอย่าง

โค้ดตัวอย่างต่อไปนี้แสดงวิธีการแทนที่ข้อความโดยใช้ regular expression พร้อมสตริงที่ระบุ.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx")){
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// แทนที่คำทั้งหมดที่มีความยาว 10 ตัวอักษรหรือมากกว่า ด้วย '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
