## TextFrame.HighlightRegex เมธอด

เน้นการจับคู่ทั้งหมดของนิพจน์ประจำรูปแบบด้วยสีที่ระบุ.

```csharp
public void HighlightRegex(Regex regex, Color highlightColor, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | นิพจน์ประจำรูปแบบ Regex เพื่อดึงข้อความที่ต้องการเน้น |
| highlightColor | Color | สีที่ใช้เน้นข้อความ |
| callback | IFindResultCallback | อ็อบเจ็กต์ callback สำหรับรับผลการค้นหา [`IFindResultCallback`](../../ifindresultcallback). |

### ตัวอย่าง

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีการเน้นข้อความใน TextFrame ด้วยการใช้นิพจน์ประจำรูปแบบ.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// ทำการเน้นทุกคำที่มีความยาว 10 ตัวอักษรหรือมากกว่า
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.HighlightRegex(regex, Color.Blue, null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
