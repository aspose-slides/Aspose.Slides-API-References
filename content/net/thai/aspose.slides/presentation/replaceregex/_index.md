## Presentation.ReplaceRegex เมธอด

แทนที่การจับคู่ทั้งหมดของนิพจน์ปกติด้วยสตริงที่ระบุ

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| regex | Regex | นิพจน์ปกติ Regex เพื่อรับสตริงที่จะแทนที่ |
| newText | String | สตริงที่ใช้แทนที่การปรากฏทั้งหมดของสตริงที่ต้องการแทนที่ |
| callback | IFindResultCallback | อ็อบเจ็กต์ callback สำหรับรับผลการค้นหา [`IFindResultCallback`](../../ifindresultcallback) |

### ตัวอย่าง

ตัวอย่างโค้ดต่อไปนี้แสดงวิธีการแทนที่ข้อความโดยใช้นิพจน์ปกติและสตริงที่ระบุ

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// แทนที่ทุกคำที่มีความยาว 10 ตัวอักษรหรือมากกว่าด้วย '***'
	presentation.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
