## Presentation.RefreshChartsData เมธอด

โหลดข้อมูลสำหรับแผนภูมิทั้งหมดในงานนำเสนอใหม่จากสมุดงานต้นทางของพวกมัน.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| พารามิเตอร์ | ประเภท | คำอธิบาย |
| --- | --- | --- |
| skipFailedCharts | Boolean | กำหนดว่ากระบวนการรีเฟรชจะดำเนินต่อไปหรือไม่หากแผนภูมิหนึ่งไม่สามารถอัปเดตได้ หาก `true` แผนภูมิที่ทำให้เกิดข้อยกเว้นจะถูกข้าม; หากไม่แสดงข้อยกเว้นจะถูกส่งต่อไป. |

### ตัวอย่าง

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
