## IFontsManager.PreferRegisteredFontsOverEmbedded คุณสมบัติ

ระบุว่าจะให้ฟอนต์ที่ลงทะเบียนได้รับการพิจารณาเป็นหลักเหนือฟอนต์ที่ฝังไว้ที่มีชื่อและรูปแบบฟอนต์เดียวกันหรือไม่ เมื่อเปิดใช้งาน ฟอนต์ที่ฝังไว้ที่ตรงกันจะถูกแทนที่ชั่วคราวด้วยฟอนต์ที่ลงทะเบียนที่สอดคล้องกันในระหว่างการส่งออก

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### หมายเหตุ

ค่าเริ่มต้นคือ **false**.

### ตัวอย่าง

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
