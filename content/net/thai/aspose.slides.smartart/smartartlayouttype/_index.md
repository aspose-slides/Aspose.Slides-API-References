## SmartArtLayoutType การระบุค่า

Represents layout type of a SmartArt diagram.

```csharp
public enum SmartArtLayoutType
```

### ค่า

| ชื่อ | ค่า | คำอธิบาย |
| --- | --- | --- |
| AccentProcess | `0` | ใช้เพื่อแสดงการก้าวหน้า, ไทม์ไลน์ หรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. ทำงานได้ดีในการอธิบายข้อความ Level 1 และ Level 2 ทั้งสอง. |
| AccentedPicture | `1` | ใช้เพื่อแสดงแนวคิดรูปถ่ายที่อยู่ตรงกลางพร้อมแนวคิดที่เกี่ยวข้องด้านข้าง. ข้อความ Level 1 ด้านบนปรากฏเหนือรูปภาพศูนย์กลาง. ข้อความที่สอดคล้องกับรูปแบบ Level 1 อื่น ๆ ปรากฏข้างรูปภาพวงกลมเล็ก. รูปแบบนี้ทำงานได้ดีแม้ไม่มีข้อความ. |
| AlternatingFlow | `2` | ใช้เพื่อแสดงกลุ่มข้อมูลหรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. เน้นการโต้ตอบหรือความสัมพันธ์ระหว่างกลุ่มข้อมูล. |
| AlternatingHexagons | `3` | ใช้เพื่อแสดงชุดของแนวคิดที่เชื่อมต่อกัน. ข้อความ Level 1 ปรากฏภายในหกเหลี่ยม. ข้อความ Level 2 ปรากฏนอกรูปร่าง. |
| AlternatingPictureBlocks | `4` | ใช้เพื่อแสดงชุดของรูปภาพจากบนลงล่าง. ข้อความแสดงสลับด้านขวาหรือซ้ายของรูปภาพ. |
| AlternatingPictureCircles | `5` | ใช้เพื่อแสดงชุดของรูปภาพพร้อมข้อความ. ข้อความที่สอดคล้องปรากฏในวงกลมศูนย์กลางโดยรูปภาพสลับจากซ้ายไปขวา. |
| ArrowRibbon | `6` | ใช้เพื่อแสดงแนวคิดที่เกี่ยวข้องหรือขัดแย้งพร้อมการเชื่อมต่อบางอย่าง เช่น แรงที่ต่อต้าน. สองบรรทัดแรกของข้อความ Level 1 ใช้เป็นข้อความในลูกศร. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| AscendingPictureAccentProcess | `7` | ใช้เพื่อแสดงชุดรูปภาพขึ้นลำดับพร้อมข้อความอธิบาย. ทำงานดีที่สุดกับข้อความจำนวนเล็กน้อย. |
| Balance | `8` | ใช้เพื่อเปรียบเทียบหรือแสดงความสัมพันธ์ระหว่างสองแนวคิด. แต่ละบรรทัดแรกสองบรรทัดของข้อความ Level 1 สอดคล้องกับข้อความที่ด้านบนของแต่ละด้านของจุดศูนย์กลาง. เน้นข้อความ Level 2 ซึ่งจำกัดที่สี่รูปแต่ละด้านของจุดศูนย์กลาง. ความสมดุลจะเอียงไปทางด้านที่มีรูปที่มีข้อความ Level 2 มากที่สุด. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BasicBendingProcess | `9` | ใช้เพื่อแสดงการเจริญเติบโตหรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. เพิ่มพื้นที่การแสดงผลแนวนอนและแนวตั้งสำหรับรูปทรงให้มากที่สุด. |
| BasicBlockList | `10` | ใช้เพื่อแสดงบล็อกข้อมูลที่ไม่ต่อเนื่องหรือจัดกลุ่ม. เพิ่มพื้นที่การแสดงผลแนวนอนและแนวตั้งสำหรับรูปทรงให้มากที่สุด. |
| BasicChevronProcess | `11` | ใช้เพื่อแสดงการเจริญเติบโต; ไทม์ไลน์; ขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์; หรือเพื่อเน้นการเคลื่อนที่หรือทิศทาง. ข้อความ Level 1 ปรากฏภายในรูปทรงลูกศรในขณะที่ข้อความ Level 2 ปรากฏใต้รูปทรงลูกศร. |
| BasicCycle | `12` | ใช้เพื่อแสดงชุดต่อเนื่องของขั้นตอน, งาน หรือเหตุการณ์ในกระบวนการวนรอบ. เน้นขั้นตอนหรือขั้นตอนมากกว่าลูกศรหรือการไหลที่เชื่อมต่อ. ทำงานดีที่สุดกับข้อความ Level 1 เท่านั้น. |
| BasicMatrix | `13` | ใช้เพื่อแสดงความสัมพันธ์ของส่วนประกอบต่อทั้งหมดในสี่ส่วน. สี่บรรทัดแรกของข้อความ Level 1 ปรากฏในแต่ละส่วน. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BasicPie | `14` | ใช้เพื่อแสดงว่าชิ้นส่วนแต่ละส่วนรวมเป็นทั้งหมดอย่างไร. เจ็ดบรรทัดแรกของข้อความ Level 1 สอดคล้องกับรูปแวกลูกหรือพายที่กระจายอย่างเท่าเทียม. รูปข้อความ Level 1 ด้านบนปรากฏนอกพายส่วนที่เหลือเพื่อเน้น. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BasicProcess | `15` | ใช้เพื่อแสดงการเจริญเติบโตหรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. |
| BasicPyramid | `16` | ใช้เพื่อแสดงความสัมพันธ์เชิงสัดส่วน, เชื่อมต่อกันหรือแบบลำดับชั้นโดยส่วนที่ใหญ่ที่สุดอยู่ด้านล่างและค่อยแคบขึ้นไปข้างบน. ข้อความ Level 1 ปรากฏในส่วนต่าง ๆ ของพีระมิดและข้อความ Level 2 ปรากฏในรูปทรงข้างๆ แต่ละส่วน. |
| BasicRadial | `17` | ใช้เพื่อแสดงความสัมพันธ์ต่อแนวคิดศูนย์กลางในรูปแบบวนรอบ. บรรทัดแรกของข้อความ Level 1 สอดคล้องกับรูปร่างศูนย์กลางและข้อความ Level 2 ของมันสอดคล้องกับรูปร่างวงกลมรอบ ๆ. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BasicTarget | `18` | ใช้เพื่อแสดงการบรรจุ, การเปลี่ยนระดับหรือความสัมพันธ์แบบลำดับชั้น. ห้าบรรทัดแรกของข้อความ Level 1 เชื่อมโยงกับวงกลม. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BasicTimeline | `19` | ใช้เพื่อแสดงขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์ หรือเพื่อแสดงข้อมูลไทม์ไลน์. ทำงานได้ดีทั้งกับข้อความ Level 1 และ Level 2. |
| BasicVenn | `20` | ใช้เพื่อแสดงความสัมพันธ์ที่ทับซ้อนหรือเชื่อมต่อกัน. เจ็ดบรรทัดแรกของข้อความ Level 1 สอดคล้องกับวงกลม. หากมีข้อความ Level 1 สี่บรรทัดหรือค่าน้อยกว่านั้น ข้อความอยู่ภายในวงกลม. หากมีมากกว่าสี่บรรทัด ข้อความอยู่ภายนอกวงกลม. ข้อความที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. |
| BendingPictureAccentList | `21` | ใช้เพื่อแสดงบล็อกข้อมูลที่ไม่ต่อเนื่องหรือจัดกลุ่ม. รูปทรงวงกลมเล็กออกแบบให้บรรจุรูปภาพ. ทำงานได้ดีสำหรับการอธิบายข้อความ Level 1 และ Level 2. เพิ่มพื้นที่การแสดงผลแนวนอนและแนวตั้งสำหรับรูปทรงให้มากที่สุด. |
| BendingPictureBlocks | `22` | ใช้เพื่อแสดงชุดรูปภาพ. กล่องที่ครอบมุมล่างสามารถบรรจุข้อความจำนวนเล็กน้อย. |
| BendingPictureCaption | `23` | ใช้เพื่อแสดงชุดรูปภาพต่อเนื่อง. กล่องที่ครอบมุมล่างสามารถบรรจุข้อความจำนวนเล็กน้อย. |
| BendingPictureCaptionList | `24` | ใช้เพื่อแสดงชุดรูปภาพ. ชื่อและคำอธิบายปรากฏในรูปแบบคำบรรยายใต้แต่ละรูปภาพ. |
| BendingPictureSemiTransparentText | `25` | ใช้เพื่อแสดงชุดรูปภาพ. กล่องกึ่งโปร่งแสงครอบส่วนล่างของรูปภาพและบรรจุตำแหน่งข้อความทั้งหมด. |
| BlockCycle | `26` | ใช้เพื่อแสดงชุดต่อเนื่องของขั้นตอน, งาน หรือเหตุการณ์ในกระบวนการวนรอบ. เน้นขั้นตอนหรือขั้นตอนมากกว่าลูกศรหรือการไหลที่เชื่อมต่อ. |
| BubblePictureList | `27` | ใช้เพื่อแสดงชุดรูปภาพ. สามารถบรรจุรูปภาพ Level 1 ได้สูงสุดแปดรูป. ข้อความและรูปภาพที่ไม่ได้ใช้จะไม่ปรากฏ แต่ยังคงอยู่หากเปลี่ยนรูปแบบ. ทำงานดีที่สุดกับข้อความจำนวนน้อย. |
| CaptionedPictures | `28` | ใช้เพื่อแสดงรูปภาพพร้อมข้อความหลายระดับ. ทำงานดีที่สุดกับข้อความ Level 1 จำนวนเล็กน้อยและข้อความ Level 2 ปริมาณกลาง. |
| ChevronList | `29` | ใช้เพื่อแสดงการเจริญเติบโตผ่านหลายกระบวนการที่ประกอบเป็นเวิร์กโฟลว์ทั้งหมด. ยังทำงานได้ดีสำหรับการแสดงกระบวนการที่ขัดแย้ง. ข้อความ Level 1 สอดคล้องกับรูปทรงลูกศรแรกทางซ้าย, ส่วนข้อความ Level 2 สอดคล้องกับขั้นตอนย่อยแนวนอนสำหรับแต่ละรูปทรงที่มีข้อความ Level 1. |
| CircleAccentTimeline | `30` | ใช้เพื่อแสดงชุดเหตุการณ์หรือข้อมูลไทม์ไลน์. ข้อความ Level 1 ปรากฏข้างรูปร่างวงกลมใหญ่. ข้อความ Level 2 ปรากฏข้างรูปร่างวงกลมเล็ก. |
| CircleArrowProcess | `31` | ใช้เพื่อแสดงรายการต่อเนื่องพร้อมข้อความสนับสนุนสำหรับแต่ละรายการ. แผนภูมินี้ทำงานดีที่สุดกับข้อความ Level 1 จำนวนเล็กน้อย. |
| CirclePictureHierarchy | `32` | ใช้เพื่อแสดงข้อมูลเชิงลำดับหรือความสัมพันธ์การรายงานในองค์กร. รูปภาพปรากฏในวงกลมและข้อความที่สอดคล้องปรากฏข้างรูปภาพ. |
| CircleRelationship | `33` | ใช้เพื่อแสดงความสัมพันธ์ต่อหรือมาจากแนวคิดศูนย์กลาง. ข้อความ Level 2 เพิ่มอย่างไม่ต่อเนื่องและจำกัดที่ห้ารายการ. สามารถมีรายการ Level 1 ได้เพียงหนึ่งรายการ. |
| CircularBendingProcess | `34` | ใช้เพื่อแสดงลำดับหรือขั้นตอนที่ยาวหรือไม่เป็นเส้นตรงในงาน, กระบวนการ หรือเวิร์กโฟลว์. ทำงานดีที่สุดกับข้อความ Level 1 เท่านั้น. เพิ่มพื้นที่การแสดงผลแนวนอนและแนวตั้งสำหรับรูปทรงให้มากที่สุด. |
| CircularPictureCallout | `35` | ใช้เพื่อแสดงแนวคิดศูนย์กลางและแนวคิดย่อยหรือรายการที่เกี่ยวข้อง. ข้อความสำหรับรูปภาพแรกครอบส่วนล่างของรูป. ข้อความที่สอดคล้องกับรูปแบบ Level 1 อื่นปรากฏข้างรูปภาพวงกลมเล็ก. แผนภูมินี้ทำงานได้ดีแม้ไม่มีข้อความ. |
| ClosedChevronProcess | `36` | ใช้เพื่อแสดงการเจริญเติบโต, ไทม์ไลน์ หรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์ หรือเพื่อเน้นการเคลื่อนที่หรือทิศทาง. สามารถใช้เพื่อเน้นข้อมูลในรูปแบบเริ่มต้น. ทำงานดีที่สุดกับข้อความ Level 1 เท่านั้น. |
| ContinuousArrowProcess | `37` | ใช้เพื่อแสดงไทม์ไลน์หรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. ทำงานดีที่สุดกับข้อความ Level 1 เนื่องจากแต่ละบรรทัดของข้อความ Level 1 ปรากฏภายในรูปทรงลูกศร. ข้อความ Level 2 ปรากฏนอกรูปทรงลูกศร. |
| ContinuousBlockProcess | `38` | ใช้เพื่อแสดงการเจริญเติบโตหรือขั้นตอนต่อเนื่องในงาน, กระบวนการ หรือเวิร์กโฟลว์. ทำงานดีที่สุดกับข้อความ Level 1 และ Level 2 ที่น้อยที่สุด. |
| ContinuousCycle | `39` | ใช้เพื่อแสดงชุดต่อเนื่องของขั้นตอน, งาน หรือเหตุการณ์ในกระบวนการวนรอบ. เน้นการเชื่อมต่อระหว่างส่วนประกอบทั้งหมด. ทำงานดีที่สุดกับข้อความ Level 1 เท่านั้น. |
