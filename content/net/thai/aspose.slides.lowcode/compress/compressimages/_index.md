## วิธีการ Compress.CompressImages

ลดความละเอียดของรูปภาพในงานนำเสนอและลบพื้นที่ที่ถูกครอบออก, คล้ายกับฟังก์ชัน “Compress Pictures” ของ PowerPoint ที่ใช้กับรูปภาพทั้งหมด. รูปภาพบนสไลด์, สไลด์เลเอาต์และสไลด์มาสเตอร์จะถูกประมวลผล, รวมถึงรูปภาพภายในกลุ่มรูปทรงและการเติมรูปภาพของรูปทรง.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| พารามิเตอร์ | ชนิด | คำอธิบาย |
| --- | --- | --- |
| presentation | IPresentation | การนำเสนอที่จะประมวลผล. |
| resolution | PicturesCompression | ความละเอียดเป้าหมายสัมพันธ์กับขนาดที่แต่ละรูปภาพถูกแสดงผล. DocumentResolution จะปล่อยให้รูปภาพคงเดิม. |

### ข้อยกเว้น

| ข้อยกเว้น | เงื่อนไข |
| --- | --- |
| ArgumentNullException | *presentation* เป็น `null`. |

### หมายเหตุ

รูปภาพที่มีความละเอียดเท่ากับหรือใต้เป้าหมายจะไม่ถูกเปลี่ยนแปลง; รูปภาพจะไม่ถูกขยายขึ้น.

ไม่ประมวลผล: พื้นหลังสไลด์, การเติมเซลล์ตาราง, แผนภูมิ, SmartArt, รูป GIF (เพื่อรักษาการเคลื่อนไหว), รูป SVG และเมตาไฟล์ (EMF/WMF).

พื้นที่ที่ถูกครอบจะถูกลบอย่างถาวรและไม่สามารถกู้คืนได้ใน PowerPoint.

### ตัวอย่าง

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
