## Compress.CompressPresentation เมธอด

ลดขนาดของงานนำเสนอโดยใช้ขั้นตอนการบีบอัดทั้งหมดที่มีอยู่:

* ลบสไลด์มาสเตอร์ที่ไม่ได้ใช้ [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* ลบสไลด์เลย์เอาต์ที่ไม่ได้ใช้ [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* เก็บเฉพาะ glyph ที่ถูกใช้จริงในฟอนต์ที่ฝังไว้ [`CompressEmbeddedFonts`](../compressembeddedfonts).
* ลดความละเอียดของรูปภาพเป็น 150 DPI และลบพื้นที่ที่ถูกครอปของรูปภาพ [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Parameter | Type | Description |
| --- | --- | --- |
| presentation | Presentation | งานนำเสนอที่จะบีบอัด |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *presentation* เป็น `null`. |

### Remarks

หากต้องการปรับแต่งการบีบอัด，例如ใช้ความละเอียดของรูปภาพที่แตกต่างหรือข้ามขั้นตอนใดขั้นตอนหนึ่ง ให้เรียกเมธอดที่ระบุข้างต้นแต่ละเมธอดแทนการใช้เมธอดนี้ พื้นที่ที่ถูกครอปของรูปภาพจะถูกลบอย่างถาวรและไม่สามารถกู้คืนได้ใน PowerPoint.

### Examples

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
