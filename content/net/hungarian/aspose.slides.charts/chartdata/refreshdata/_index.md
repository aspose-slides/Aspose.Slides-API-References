## ChartData.RefreshData metódus

A diagram adatainak frissítése a forrásmunkafüzet újratöltésével.

```csharp
public void RefreshData()
```

### Kivételek

| kivétel | feltétel |
| --- | --- |
| InvalidOperationException | Kivétel akkor, ha a munkafüzet formátuma nem támogatott, vagy ha [`DataSourceType`](../datasourcetype) ExternalWorkbook, és a külső munkafüzet nem érhető el vagy nem tölthető be. |

### Megjegyzések

Ha a diagram külső munkafüzetet használ, a munkafüzetnek elérhetőnek kell lennie a hívás időpontjában.

### Példák

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
