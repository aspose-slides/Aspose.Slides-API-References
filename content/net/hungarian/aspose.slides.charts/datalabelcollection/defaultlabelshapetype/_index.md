## DataLabelCollection.DefaultLabelShapeType tulajdonság

Lekérdezi vagy beállítja a adatcímkék alapértelmezett alakzat típusát. Visszaadja a NotDefined értéket, ha nincs meghatározott alakzat.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Megjegyzések

Ennek a tulajdonságnak a beállítása szintén beállítja a [`LabelShapeType`](../../idatalabel/labelshapetype) tulajdonságot a gyűjteményben lévő összes adatcímkére ugyanarra az értékre.

### Példák

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Állítsa be az első sorozat összes adatcímkéjének alakzat típusát Ellipse-re.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
