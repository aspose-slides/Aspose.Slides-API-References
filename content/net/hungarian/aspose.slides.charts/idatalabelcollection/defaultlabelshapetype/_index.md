## IDataLabelCollection.DefaultLabelShapeType tulajdonság

Lekéri vagy beállítja az adatcímkék alapértelmezett alakzat típusát. NotDefined értéket ad vissza, ha nincs alakzat definiálva.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Megjegyzések

Ennek a tulajdonságnak a beállítása szintén beállítja a [`LabelShapeType`](../../idatalabel/labelshapetype) tulajdonságot a gyűjtemény összes adatcímkéjére ugyanarra az értékre.

### Példák

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Az első sorozat összes adatcímkéjének alakzat típusát Ellipse-re állítja.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
