## DataLabel.LabelShapeType tulajdonság

Visszaadja vagy beállítja a data label alakjának típusát. NotDefined-et ad vissza, ha nincs definiált alak.

```csharp
public ShapeType LabelShapeType { get; set; }
```

### Példák

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Állítsa be az első adatcímke alakját Ellipse-re.
```
