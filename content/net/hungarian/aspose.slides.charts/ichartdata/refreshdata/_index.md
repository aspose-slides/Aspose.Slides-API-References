## IChartData.RefreshData metódus

Frissíti a diagram adatokat az eredeti munkafüzetből való újratöltéssel.

```csharp
public void RefreshData()
```

### Kivételek

| kivétel | feltétel |
| --- | --- |
| InvalidOperationException | Kivétel akkor keletkezik, ha a munkafüzet formátuma nem támogatott, vagy ha [`DataSourceType`](../datasourcetype) ExternalWorkbook, és a külső munkafüzet nem érhető el vagy nem tölthető be. |

### Megjegyzés

Ha a diagram külső munkafüzetet használ, a munkafüzetnek a hívás időpontjában elérhetőnek kell lennie.

### Példák

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
