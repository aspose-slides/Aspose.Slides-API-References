## Compress.CompressImages metódus

Csökkenti a képek felbontását a bemutatóban, és eltávolítja a levágott területeket, hasonlóan a PowerPoint „Compress Pictures” funkciójához, amely minden képre alkalmazható. A diákon, elrendezési diákon és mesterdiákon található képek feldolgozásra kerülnek, beleértve a csoportos alakzatokban és alakzatok képkitöltéseiben lévő képeket.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Parameter | Type | Description |
| --- | --- | --- |
| presentation | IPresentation | A feldolgozandó prezentáció. |
| resolution | PicturesCompression | Célfelbontás a kép megjelenítésének méretéhez viszonyítva. DocumentResolution változatlanul hagyja a képeket. |

### Kivételek

| kivétel | feltétel |
| --- | --- |
| ArgumentNullException | *presentation* `null`. |

### Megjegyzések

Az már a célfelbontásnál alacsonyabb vagy egyenlő felbontású képek változatlanok maradnak; a képek soha nem lesznek felskálázva.

Nem kerül feldolgozásra: diavetítő hátterek, táblázatcellák kitöltései, diagramok, SmartArt, GIF képek (az animáció megőrzéséért), SVG és metafájl (EMF/WMF) képek.

A levágott területek véglegesen eltávolításra kerülnek, és nem állíthatók helyre a PowerPointban.

### Példák

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
