## Compress.CompressPresentation metódus

Csökkenti egy bemutató méretét az összes elérhető tömörítési lépés alkalmazásával:

* Eltávolítja a nem használt mesterdiákat [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Eltávolítja a nem használt elrendezési diákat [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Megőrzi csak azokat a glifeket, amelyeket a beágyazott betűtípusok ténylegesen használnak [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Csökkenti a képek felbontását 150 DPI-re, és törli a képek levágott területeit [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| presentation | Presentation | A tömörítendő bemutató. |

### Kivételek

| kivétel | feltétel |
| --- | --- |
| ArgumentNullException | *presentation* `null`. |

### Megjegyzések

A tömörítés testreszabásához, például egy másik képfelbontás használatához vagy egy lépés kihagyásához, hívja meg a fent felsorolt metódusokat egyenként e helyett. A képek levágott részei véglegesen eltávolításra kerülnek, és a PowerPointban nem állíthatók helyre.

### Példák

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
