## Presentation.RefreshChartsData metódus

Újratölti a prezentáció összes diagramjának adatait a forrás munkafüzetekből.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| skipFailedCharts | Boolean | Meghatározza, hogy a frissítési folyamat folytatódik-e, ha egy diagram frissítése sikertelen. Ha `true`, a kivételt okozó diagramok átugrásra kerülnek; egyébként a kivétel továbbadódik. |

### Példák

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
