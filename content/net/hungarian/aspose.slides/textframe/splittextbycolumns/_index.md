## TextFrame.SplitTextByColumns metódus

Felosztja a [`ITextFrame`](../../itextframe) szövegtartalmát egy karakterláncok tömbjére, ahol minden elem egy külön szövegoszlopnak felel meg a keretben.

```csharp
public string[] SplitTextByColumns()
```

### Visszatérési érték

Egy karakterláncok tömbje, ahol minden karakterlánc egy adott oszlop szövegtartalmát reprezentálja a [`ITextFrame`](../../itextframe)-ban.

### Megjegyzések

Ha a szövegkeret nem tartalmaz több oszlopot, a visszakapott tömb egyetlen elemet fog tartalmazni, amely a teljes szöveget tartalmazza. Az üres oszlopok a tömbben üres karakterláncként lesznek ábrázolva.

### Példák

Az alábbi példa bemutatja, hogyan kell használni a `SplitTextByColumns`:

```csharp
using (Presentation pres = new Presentation("example.pptx"))
{
    // Az első alakzat lekérése a dián, és átkonvertálása ITextFrame-re
    ITextFrame textFrame = pres.Slides[0].Shapes[0] as ITextFrame;
    // A szövegkeret tartalmának oszlopokra bontása
    string[] columnsText = textFrame.SplitTextByColumns();
    // Minden oszlop szövegének kiírása a konzolra
    foreach (string column in columnsText)
        Console.WriteLine(column);
}
```
