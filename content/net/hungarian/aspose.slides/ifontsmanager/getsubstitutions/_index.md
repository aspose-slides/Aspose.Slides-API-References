## GetSubstitutions() {#getsubstitutions}

A prezentáció renderelése során helyettesítendő betűtípusokról ad információt.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions()
```

### Visszatérési érték

Az összes betűtípus-helyettesítés gyűjteménye [`FontSubstitutionInfo`](../../fontsubstitutioninfo).

### Példák

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions())
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```

## GetSubstitutions(int[]) {#getsubstitutions_1}

Az adott diák renderelése során helyettesítendő betűtípusokról ad információt.

```csharp
public IEnumerable<FontSubstitutionInfo> GetSubstitutions(int[] slides)
```

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| slides | Int32[] | Azon dia indexek tömbje, amelyekhez a betűtípus-helyettesítési információkat kell lekérni, 1-től kezdve. |

### Visszatérési érték

A megadott diákra vonatkozó összes betűtípus-helyettesítés ([`FontSubstitutionInfo`](../../fontsubstitutioninfo)) gyűjteménye.

### Példák

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    int[] targetSlides = { 1, 2, 5 };
    foreach (var fontSubstitution in pres.FontsManager.GetSubstitutions(targetSlides))
    {
        Console.WriteLine("{0} -> {1}", fontSubstitution.OriginalFontName, fontSubstitution.SubstitutedFontName);
    }
}
```
