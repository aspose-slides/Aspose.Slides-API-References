## IFontsManager.PreferRegisteredFontsOverEmbedded tulajdonság

Megadja, hogy a regisztrált betűkészletek előnyben részesüljenek-e a beágyazott betűkészletekkel azonos betűnév és stílus esetén. Ha engedélyezve van, a megfelelő beágyazott betűkészletek ideiglenesen a megfelelő regisztrált betűkészletekkel helyettesítődnek az exportálás során.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Megjegyzés

Az alapértelmezett érték **false**.

### Példák

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
