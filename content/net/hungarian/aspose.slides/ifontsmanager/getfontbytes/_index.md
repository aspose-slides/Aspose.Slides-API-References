## IFontsManager.GetFontBytes metódus

Lekérdezi a megadott betűstílus és betűadatokhoz tartozó betűadatokat képviselő bájt tömböt.

```csharp
public byte[] GetFontBytes(IFontData fontData, FontStyleType fontStyle)
```

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| fontData | IFontData | A betűadat-objektum, amely tartalmazza a betűről [`IFontData`](../../ifontdata). |
| fontStyle | FontStyleType | A betű stílusa, amelyhez az adatot le kell kérni [`FontStyleType`](../../fontstyletype). |

### Visszatérési érték

A megadott betűstílushoz tartozó betűadatokat tartalmazó bájt tömb. Ha a betűadat vagy a stílus nem található, null értéket ad vissza.

### Példák

```csharp
[C#]
using (Presentation pres = new Presentation ("Presentation.pptx"))
{
    // A bemutatóban használt összes betűt lekéri
    IFontData[] fonts = pres.FontsManager.GetFonts();

    // Lekéri a bemutató első betűjének szabályos stílusához tartozó bájt tömböt
    byte[] bytes = pres.FontsManager.GetFontBytes(fonts[0], FontStyleType.Regular);
}
```
