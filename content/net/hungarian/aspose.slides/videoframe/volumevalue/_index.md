## VideoFrame.VolumeValue tulajdonság

Visszaadja vagy beállítja a pontos videóhangerőt százalékban. Az érték százalékban van kifejezve, 0 és 100 között. Használja ezt a tulajdonságot a hangerőértékek olvasásához vagy beállításához, amelyek pontosabbak, mint a [`Volume`](../volume) tulajdonság által elérhető előre meghatározott szintek. Olvasás/írás Single.

```csharp
public float VolumeValue { get; set; }
```

### Példák

Példa:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Olvassa ki a jelenlegi pontos hangerőt, és állítsa be 75.5 százalékra.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
