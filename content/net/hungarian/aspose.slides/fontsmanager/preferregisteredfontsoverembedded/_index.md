## FontsManager.PreferRegisteredFontsOverEmbedded tulajdonság

Megadja, hogy a regisztrált betűkészletek előnyben részesüljenek-e a ugyanazzal a betűkészletnévvel és stílussal rendelkező beágyazott betűkészletekkel szemben. Ha engedélyezve van, a megfelelő beágyazott betűkészletek ideiglenesen a megfelelő regisztrált betűkészletekkel kerülnek helyettesítésre exportálás közben.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Megjegyzések

Az alapértelmezett érték **false**.

### Példák

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
