## ExternalResourceResolver класс

Класс обратного вызова, используемый для разрешения внешних ресурсов при импорте документов Html, Svg. Использование этого резольвера может создать уязвимость, когда предоставленный клиентом HTML или SVG файл заставит серверное программное обеспечение получать локальные или сетевые файлы. Используйте с осторожностью. Рекомендуется не указывать ExternalResourceResolver вовсе (будут прочитаны только встроенные объекты) или создать подкласс, который проверяет, является ли указанный uri действительным.

```csharp
public class ExternalResourceResolver : IExternalResourceResolver
```
