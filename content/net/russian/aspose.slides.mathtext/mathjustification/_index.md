## MathJustification перечисление

Указывает выравнивание математического абзаца (серия смежных вхождений математического текста в пределах одного абзаца)

```csharp
public enum MathJustification
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| LeftJustified | `1` | Выравнивает математический текст по левому краю |
| RightJustified | `2` | Выравнивает математический текст по правому краю |
| Centered | `3` | Выравнивает математический текст по центру |
| CenteredAsGroup | `4` | Центрирует на странице всю группу блоков математического текста как единое целое. Это означает, что отдельные вхождения математического текста могут быть выровнены относительно друг друга, но вся группа математического текста центрируется как целое. |
