## ChartData.RefreshData метод

Обновляет данные диаграммы, перезагружая их из исходной рабочей книги.

```csharp
public void RefreshData()
```

### Исключения

| исключение | условие |
| --- | --- |
| InvalidOperationException | Выбрасывается, когда формат рабочей книги не поддерживается, или когда [`DataSourceType`](../datasourcetype) имеет значение ExternalWorkbook и внешняя рабочая книга недоступна или не может быть загружена. |

### Примечания

Если диаграмма использует внешнюю рабочую книгу, рабочая книга должна быть доступна во время вызова.

### Примеры

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
