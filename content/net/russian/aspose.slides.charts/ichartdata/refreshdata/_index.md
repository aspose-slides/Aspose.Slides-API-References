## IChartData.RefreshData метод

Обновляет данные диаграммы, перезагружая их из исходной книги.

```csharp
public void RefreshData()
```

### Исключения

| исключение | условие |
| --- | --- |
| InvalidOperationException | Выбрасывается, когда формат книги не поддерживается, или когда [`DataSourceType`](../datasourcetype) имеет значение ExternalWorkbook и внешнюю книгу невозможно открыть или загрузить. |

### Примечания

Если диаграмма использует внешнюю книгу, книга должна быть доступна во время вызова.

### Примеры

```csharp
using (var presentation = new Presentation("presentationWithChart.pptx"))
{
    var chart = (IChart)presentation.Slides[0].Shapes[0];
    chart.ChartData.RefreshData();
}
```
