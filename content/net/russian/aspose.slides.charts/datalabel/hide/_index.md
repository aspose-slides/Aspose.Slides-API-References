## DataLabel.Hide метод

Сделайте метку данных скрытой, установив все флаги Show*-flags (ShowValue, ...) в состояние false. IsVisible будет равно false после этого.

```csharp
public void Hide()
```

### Примечания

Если метка данных не видима (IsVisible равно false), вы можете сделать её видимой, установив флаги Show*-flags (ShowValue, ...) в состояние true.
