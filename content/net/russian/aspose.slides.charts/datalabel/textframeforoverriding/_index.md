## DataLabel.TextFrameForOverriding свойство

Может содержать форматированный текст. Если это свойство не равно null, то значение этого форматированного текста переопределяет автоматически сгенерированный текст подписи данных. Автоматически сгенерированный текст подписи данных представляет собой текст, который управляется свойствами ShowSeriesName, ShowValue, ... и форматируется свойством TextFormatManager.TextFormat. Только для чтения [`ITextFrame`](../../../aspose.slides/itextframe).

```csharp
public ITextFrame TextFrameForOverriding { get; }
```
