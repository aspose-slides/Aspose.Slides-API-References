## ChartCategory.UseCell свойство

Если true, то свойство AsCell актуально. Другими словами, рабочий лист используется для хранения категории (в этом случае поддерживается многоуровневая категория). Если false, то свойство AsLiteral актуально. Другими словами, рабочий лист НЕ используется для хранения категории (и в этом случае не поддерживаются многоуровневые категории). Только для чтения Boolean.

```csharp
public bool UseCell { get; }
```

### Примечания

Чтобы изменить значение этого свойства (для всех категорий в коллекции), установите новое значение свойства ChartCategoryCollection.UseCells.
