## DataLabelCollection.Hide метод

Сделайте подпись данных скрытой по умолчанию, установив все Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat в состояние false. IsVisible будет false после этого.

```csharp
public void Hide()
```

### Примечания

Если подпись данных не видима по умолчанию (IsVisible равно false), вы можете сделать подпись данных \"видимой по умолчанию\", установив Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat в состояние true.
