## DataLabelCollection.IsVisible свойство

False means that data label is not visible by default (and so all Show*-flags (ShowValue, ...) of the DefaultDataLabelFormat свойство are false). Только для чтения Boolean.

```csharp
public bool IsVisible { get; }
```

### Примечания

If data label is visible by default you can make it hidden by default with Hide() метод. But if data label is not visible by default (IsVisible is false) you can make data label "visible by default" with setting Show*-flags (ShowValue, ...) of the DefaultDataLabelFormat свойство to true state.
