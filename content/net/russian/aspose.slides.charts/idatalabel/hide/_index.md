## IDataLabel.Hide метод

Сделайте подпись данных скрытой, установив все флаги Show*-flags (ShowValue, ...) в состояние false. IsVisible будет false после этого.

```csharp
public void Hide()
```

### Примечания

Если подпись данных не видима (IsVisible is false), вы можете сделать подпись данных видимой, установив флаги Show*-flags (ShowValue, ...) в состояние true.
