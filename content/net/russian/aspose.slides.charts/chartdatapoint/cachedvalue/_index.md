## ChartDataPoint.CachedValue свойство

Получает кэшированное значение точки данных диаграммы. Только для чтения [`ICachedChartValue`](../../icachedchartvalue).

```csharp
public ICachedChartValue CachedValue { get; }
```

### Примеры

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[0];
    foreach (var series in chart.ChartData.Series)
    {
        // Вывести все кэшированные значения серии диаграммы.
        foreach (var point in series.DataPoints)
            Console.WriteLine(point.CachedValue.ToDouble());
    }
}
```
