## ChartShapeType перечисление

Представляет форму chart.

```csharp
public enum ChartShapeType
```

### Значения

| Name | Value | Description |
| --- | --- | --- |
| NotDefined | `-1` | Форма Chart не определена. |
| Box | `0` | Указывает, что chart будет нарисована в виде прямоугольного контейнера. |
| Cone | `1` | Указывает, что chart будет нарисована в виде конуса, при этом основание конуса находится на полу, а вершина конуса — в верхней части маркера данных. |
| ConeToMax | `2` | Указывает, что chart будет нарисована с усечёнными конусами так, что вершина конуса будет соответствовать максимальному значению данных. |
| Cylinder | `3` | Указывает, что chart будет нарисована в виде цилиндра. |
| Pyramid | `4` | Указывает, что chart будет нарисована в виде прямоугольной пирамиды, при этом основание пирамиды находится на полу, а вершина пирамиды — в верхней части маркера данных. |
| PyramidToMaximum | `5` | Указывает, что chart будет нарисована с усечёнными конусами так, что вершина конуса будет соответствовать максимальному значению данных. |
