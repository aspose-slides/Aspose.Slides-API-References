## IChartSeriesGroup.GapDepth свойство

Получает или задает расстояние между сериями данных в 3D-диаграмме в процентах от ширины маркера. Значение должно быть от 0 до 500. Чтение/запись UInt16.

```csharp
public ushort GapDepth { get; set; }
```

### Примечания

Это свойство применяется к сериям следующих типов: 3D bar and column subtypes, Line3D, Area3D, StackedArea3D, PercentsStackedArea3D.
