## Перечисление PieSplitType

Представляет тип точек разбиения во втором секторе или столбце диаграммы «pie-of-pie» или «bar-of-pie».

```csharp
public enum PieSplitType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | Указывает, что точки данных должны быть разбиты с использованием механизма по умолчанию для данного типа диаграммы. |
| Custom | `1` | Указывает, что точки данных должны быть разбиты между кругом и вторым графиком согласно значениям Custom Split. |
| ByPercentage | `2` | Указывает, что точки данных должны быть разбиты между кругом и вторым графиком, помещая точки с процентом меньше Split Position процентов во второй график. |
| ByPos | `3` | Указывает, что точки данных должны быть разбиты между кругом и вторым графиком, помещая последний Split Position точек данных во второй график. |
| ByValue | `4` | Указывает, что точки данных должны быть разбиты между кругом и вторым графиком, помещая точки данных со значением меньше Split Position во второй график. |
