## IDataLabelCollection.Hide метод

Сделать метку данных скрытой по умолчанию, установив все флаги Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat в состояние false. IsVisible будет false после этого.

```csharp
public void Hide()
```

### Примечания

Если метка данных не видима по умолчанию (IsVisible равно false), вы можете сделать её «видимой по умолчанию», установив флаги Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat в состояние true.
