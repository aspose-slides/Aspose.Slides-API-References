## IDataLabelCollection.DefaultLabelShapeType свойство

Получает или задает тип формы по умолчанию для подписей данных. Возвращает NotDefined, если форма не определена.

```csharp
public ShapeType DefaultLabelShapeType { get; set; }
```

### Примечания

Установка этого свойства также задает свойство [`LabelShapeType`](../../idatalabel/labelshapetype) для всех подписей данных в коллекции тем же значением.

### Примеры

```csharp
[C#]
using (Presentation pres = new Presentation("Chart.pptx"))
{
    var chart = (IChart)pres.Slides[0].Shapes[1];
    var firstSeries = chart.ChartData.Series[0];

    // Установить тип формы для всех подписей данных в первой серии в значение Ellipse.
    firstSeries.Labels.DefaultLabelShapeType = ShapeType.Ellipse;

    pres.Save("ChartWithEllipseLabels.pptx", SaveFormat.Pptx);
}
```
