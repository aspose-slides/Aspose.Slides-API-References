## IDataLabelCollection.IsVisible свойство

False означает, что подпись данных по умолчанию не видима (и поэтому все Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat имеют значение false). Только для чтения Boolean.

```csharp
public bool IsVisible { get; }
```

### Замечания

Если подпись данных видима по умолчанию, вы можете сделать её скрытой по умолчанию с помощью метода Hide(). Но если подпись данных не видима по умолчанию (IsVisible is false) вы можете сделать подпись данных «видимой по умолчанию», установив флаги Show*-flags (ShowValue, ...) свойства DefaultDataLabelFormat в состояние true.
