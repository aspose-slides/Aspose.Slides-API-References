## Compress.CompressImages метод

Уменьшает разрешение изображений в презентации и удаляет их обрезанные области, аналогично функции PowerPoint «Compress Pictures», применяемой ко всем изображениям. Изображения на слайдах, шаблонных слайдах и мастерах обрабатываются, включая изображения внутри групповых фигур и заполнения изображениями фигур.

```csharp
public static void CompressImages(IPresentation presentation, PicturesCompression resolution)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| presentation | IPresentation | Презентация для обработки. |
| resolution | PicturesCompression | Целевое разрешение относительно размера, в котором отображается каждое изображение. DocumentResolution оставляет изображения без изменений. |

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentNullException | *presentation* равно `null`. |

### Примечания

Изображения, уже имеющие целевое разрешение или ниже его, остаются без изменений; изображения никогда не увеличиваются.

Не обрабатываются: фоны слайдов, заливки ячеек таблиц, диаграммы, SmartArt, GIF-изображения (для сохранения анимации), SVG и метафайлы (EMF/WMF).

Обрезанные области удаляются навсегда и не могут быть восстановлены в PowerPoint.

### Примеры

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    CompressImages(pres, PicturesCompression.Dpi150);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
