## Метод Compress.CompressPresentation

Уменьшает размер презентации, применяя все доступные шаги сжатия:

* Удаляет неиспользованные главные слайды [`RemoveUnusedMasterSlides`](../removeunusedmasterslides).
* Удаляет неиспользованные макетные слайды [`RemoveUnusedLayoutSlides`](../removeunusedlayoutslides).
* Сохраняет только те глифы, которые действительно используются во встроенных шрифтах [`CompressEmbeddedFonts`](../compressembeddedfonts).
* Уменьшает разрешение изображений до 150 DPI и удаляет обрезанные области изображений [`CompressImages`](../compressimages).

```csharp
public static void CompressPresentation(Presentation presentation)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| presentation | Presentation | Презентация, которую нужно сжать. |

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentNullException | *presentation* равен `null`. |

### Примечания

Чтобы настроить сжатие, например использовать другое разрешение изображений или пропустить шаг, вызывайте перечисленные выше методы по отдельности вместо этого. Обрезанные области изображений удаляются навсегда и не могут быть восстановлены в PowerPoint.

### Примеры

```csharp
using (Presentation pres = new Presentation("pres.pptx"))
{
    Aspose.Slides.LowCode.Compress.CompressPresentation(pres);
    
    pres.Save("pres-out.pptx", SaveFormat.Pptx);
}
```
