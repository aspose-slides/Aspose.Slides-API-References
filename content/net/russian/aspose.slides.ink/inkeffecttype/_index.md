## InkEffectType перечисление

Определяет набор предопределённых визуальных эффектов для отрисовки чернил. Каждый эффект соответствует текстуре или изображению, имитирующему стилизованный вид чернил. Эти значения могут использоваться для настройки визуального стиля цифровых штрихов чернил во время отрисовки.

```csharp
public enum InkEffectType
```

| Имя | Значение | Описание |
| --- | --- | --- |
| NotDefined | `-1` | Эффект не определён или неизвестен. Это значение может использоваться как значение по умолчанию или резервное. |
| Bronze | `0` | Тёплая, коричневатая металлическая текстура, напоминающая бронзовые чернила. |
| Galaxy | `1` | Яркая, мерцающая текстура, напоминающая галактику, с космическими оттенками. |
| Gold | `2` | Светлая, металлическая золотая текстура, придающая штрихам чернил роскошный вид. |

| RainbowGlitter | `5` | Яркий, искрящийся радужный блеск, используемый для праздничных или живых штрихов чернил. |

| Silver | `7` | Холодная, металлическая серебряная текстура, имитирующая классические серебряные чернила. |
