## Zip64Mode перечисление

Указывает, когда использовать расширения формата ZIP64 для файла OpenXML.

```csharp
public enum Zip64Mode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Never | `0` | Не использовать расширения формата ZIP64. |
| IfNecessary | `1` | Использовать расширения формата ZIP64 при необходимости. |
| Always | `2` | Всегда использовать расширения формата ZIP64. |

### Примечания

Файл OpenXML представляет собой ZIP-архив, у которого есть ограничение в 4 ГБ (2^32 байт) на размер несжатого файла, сжатый размер файла и общий размер архива, а также ограничение в 65 535 (2^16-1) файлов в архиве. Расширения формата ZIP64 увеличивают ограничения до 2^64.
