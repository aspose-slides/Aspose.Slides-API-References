## SvgEvent перечисление

Представляет варианты для SVG-формы.

public enum SvgEvent

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| OnFocusIn | `0` | Происходит, когда элемент получает фокус, например, когда текст выделяется. |
| OnFocusOut | `1` | Происходит, когда элемент теряет фокус, например, когда текст перестаёт быть выделенным. |
| OnActivate | `2` | Происходит, когда элемент активируется, например, через щелчок мыши или нажатие клавиши. |
| OnClick | `3` | Происходит, когда кнопка указательного устройства нажимается над элементом. |
| OnMouseDown | `4` | Происходит, когда кнопка указательного устройства нажата над элементом. |
| OnMouseUp | `5` | Происходит, когда кнопка указательного устройства отпускается над элементом. |
| OnMouseOver | `6` | Происходит, когда указательное устройство перемещается на элемент. |
| OnMouseMove | `7` | Происходит, когда указательное устройство перемещается, находясь над элементом. |
| OnMouseOut | `8` | Происходит, когда указательное устройство уходит от элемента. |
| OnLoad | `9` | Происходит, когда пользовательский агент полностью разобрал элемент и его потомков, а также все ссылки на ресурсы, необходимые для его отображения. |
| OnUnload | `10` | Происходит, когда реализация DOM удаляет документ из окна или фрейма. Применимо только к внешним элементам svg. |
| OnAbort | `11` | Происходит, когда загрузка страницы останавливается до того, как элемент смог полностью загрузиться. |
| OnError | `12` | Происходит, когда элемент не загружается корректно или возникает ошибка во время выполнения скрипта. |
| OnResize | `13` | Происходит, когда представление документа изменяется в размере. Применимо только к внешним элементам svg. |
| OnScroll | `14` | Происходит, когда представление документа смещается по оси X, Y или обеим одновременно. Применимо только к внешним элементам svg. |
| OnZoom | `15` | Происходит, когда уровень масштабирования представления документа изменяется. Применимо только к внешним элементам svg. |
| OnBegin | `16` | Происходит, когда анимационный элемент начинается. |
| OnEnd | `17` | Происходит, когда анимационный элемент заканчивается. |
| OnRepeat | `18` | Происходит, когда анимационный элемент повторяется. |
