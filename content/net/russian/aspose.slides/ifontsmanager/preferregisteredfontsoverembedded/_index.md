## IFontsManager.PreferRegisteredFontsOverEmbedded свойство

Указывает, следует ли отдавать предпочтение зарегистрированным шрифтам вместо внедрённых шрифтов с тем же названием и стилем. При включении совпадающие внедрённые шрифты временно заменяются соответствующими зарегистрированными шрифтами во время экспорта.

```csharp
public bool PreferRegisteredFontsOverEmbedded { get; set; }
```

### Примечания

По умолчанию **false**.

### Примеры

```csharp
[C#]

using (Presentation pres = new Presentation("SomePresentation.pptx"))
{
	pres.FontManager.PreferRegisteredFontsOverEmbedded = true;
	pres.Save(@"Presentation-out.pdf", SaveFormat.Pdf);
}
```
