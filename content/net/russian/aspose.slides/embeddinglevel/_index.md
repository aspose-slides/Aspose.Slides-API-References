## EmbeddingLevel перечисление

Представляет права лицензирования для встраивания шрифта.

```csharp
[Flags]
public enum EmbeddingLevel : ushort
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Installable | `0` | Шрифты с этой настройкой указывают, что их можно встраивать и постоянно устанавливать на удалённой системе приложением. Пользователь удалённой системы получает те же права, обязательства и лицензии на этот шрифт, что и оригинальный покупатель, и подпадает под то же лицензионное соглашение конечного пользователя, авторское право, патент на дизайн и/или товарный знак, что и оригинальный покупатель. |
| Restricted | `2` | Шрифты, у которых установлен только этот бит, не должны быть изменены, встроены или обменены каким-либо способом без предварительного получения разрешения законного владельца. |
| PreviewPrint | `4` | Когда установлен этот бит, шрифт может быть встроен и временно загружен на удалённой системе. Документы, содержащие шрифты Preview &amp; Print, должны открываться «только для чтения»; изменения в документе недоступны. |
| Editable | `8` | Когда установлен этот бит, шрифт может быть встроен, но должен устанавливаться только временно на других системах. В отличие от шрифтов Preview &amp; Print, документы, содержащие шрифты Editable, могут открываться для чтения, редактирование разрешено, и изменения могут сохраняться. |
| NoSubsetting | `100` | При установленном этом бите шрифт нельзя подсекционировать перед встраиванием. Другие ограничения встраивания, указанные в битах 0-3 и 9, также применяются. |
| BitmapOnly | `200` | При установленном этом бите можно встраивать только растровые изображения, содержащиеся в шрифте. Контурные данные встраиваться не могут. Если в шрифте нет растровых изображений, шрифт считается не встраиваемым, и службы встраивания завершатся с ошибкой. |
