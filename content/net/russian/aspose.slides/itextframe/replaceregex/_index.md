## ITextFrame.ReplaceRegex method

Заменяет все совпадения регулярного выражения указанной строкой.

```csharp
public void ReplaceRegex(Regex regex, string newText, IFindResultCallback callback)
```

| Parameter | Type | Description |
| --- | --- | --- |
| regex | Regex | Регулярное выражение Regex, используемое для получения строк, которые нужно заменить. |
| newText | String | Строка, которой заменяются все вхождения строк, подлежащих замене. |
| callback | IFindResultCallback | Объект обратного вызова для получения результатов поиска [`IFindResultCallback`](../../ifindresultcallback). |

### Примеры

Следующий пример кода показывает, как заменить текст с помощью регулярного выражения указанной строкой.

```csharp
[C#]
using (Presentation presentation = new Presentation("SomePresentation.pptx"))
{
	Regex regex = new Regex(@"\b[^\s]{10,}\b");
	// Заменить все слова из 10 или более символов на '***'
	((AutoShape)presentation.Slides[0].Shapes[0]).TextFrame.ReplaceRegex(regex, "***", null);
	presentation.Save("SomePresentation-out.pptx", SaveFormat.Pptx);
}
```
