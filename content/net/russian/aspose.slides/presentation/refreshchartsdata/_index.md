## Presentation.RefreshChartsData метод

Перезагружает данные для всех диаграмм в презентации из их исходных рабочих книг.

```csharp
public void RefreshChartsData(bool skipFailedCharts = true)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| skipFailedCharts | Boolean | Определяет, продолжается ли процесс обновления, если обновление диаграммы не удалось. Если `true`, диаграммы, вызывающие исключение, пропускаются; иначе исключение передаётся дальше. |

### Примеры

```csharp
using (var presentation = new Presentation("PresentationWithCharts.pptx"))
{
    presentation.RefreshChartsData();
    presentation.Save("PresentationWithCharts-out.pptx", SaveFormat.Pptx);
}
```
