## Свойство VideoFrame.VolumeValue

Возвращает или задает точный уровень громкости видео в процентах. Значение выражается в процентах от 0 до 100. Используйте это свойство для чтения или задания значений громкости, более точных, чем предустановленные уровни, доступные через свойство [`Volume`](../volume). Чтение/запись Single.

```csharp
public float VolumeValue { get; set; }
```

### Примеры

Пример:

```csharp
[C#]
using (Presentation pres = new Presentation("video.pptx"))
{
    IVideoFrame videoFrame = (IVideoFrame)pres.Slides[0].Shapes[0];

    // Прочитать текущее точное значение громкости и установить его на 75,5 процента.
    float currentVolume = videoFrame.VolumeValue;
    videoFrame.VolumeValue = 75.5f;

    pres.Save("video_with_volume.pptx", SaveFormat.Pptx);
}
```
