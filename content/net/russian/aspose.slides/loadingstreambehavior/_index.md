## Перечисление LoadingStreamBehavior

Поток, передаваемый в метод, рассматривается как Binary Large Object (BLOB) (см. [`IBlobManagementOptions`](../iblobmanagementoptions) описание). Значения этого перечисления определяют, как следует обрабатывать поток при передаче его в метод. В зависимости от требований могут приниматься разные решения для обеспечения наибольшей эффективности.

```csharp
public enum LoadingStreamBehavior
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ReadStreamAndRelease | `0` | Поток будет прочитан до конца, а затем освобождён — то есть будет гарантировано, что этот поток больше не будет использоваться экземпляром [`IPresentation`](../ipresentation) в будущем. Его можно закрыть клиентским кодом или использовать другим способом. |
| KeepLocked | `1` | Поток будет заблокирован внутри объекта [`IPresentation`](../ipresentation), то есть владение потоком будет передано. Объект [`IPresentation`](../ipresentation) будет отвечать за корректное освобождение потока при уничтожении самого объекта. Такое поведение чрезвычайно полезно, когда требуется сериализовать большой BLOB-файл (например, большое видео или аудио — см. [`IBlobManagementOptions`](../iblobmanagementoptions) описание) и необходимо избежать загрузки этого файла в память или других проблем с производительностью. Вы можете просто открыть FileStream для этого файла и передать его в метод, выбирая KeepLocked LoadingStreamBehavior. |
